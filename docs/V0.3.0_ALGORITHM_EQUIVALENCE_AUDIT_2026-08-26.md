# dwi2cond-xp v0.3.0 算法修复与第二轮一致性审计

> 审计日期：2026-08-26
> 修复基线：v0.2.0 tag 对应提交 `20f40923bb04e146522f458332a4e2fc152d3f00`
> 官方基线：SimNIBS 4.6.0 `dwi2cond` 与 FSL `6.0.4:ddd0a010`
> 版本定位：**v0.3.0 是算法流程与计算逻辑修复版，不是加速版。**
> 结论：v0.2.0 审计发现的 19 项问题均已在代码、输入合同或明确的支持边界中关闭；
> 在下文定义的固定输入子集内，完整 DAG 已恢复官方阶段顺序、产物流向、mask、阈值、
> fitting、T1 registration、tensor reorientation 和发布逻辑。

## 1. 结论与证据边界

本轮没有把“已实现固定子集”表述为“重写了整个 FSL”。v0.3.0 的运行时支持边界为：

- 官方 pre-fitted 六分量 tensor 输入；
- raw、finite、single-shell DWI 的 `nomoco`、默认 legacy 以及 EDDY 分支；
- 已解缠且已换算为 radians/second 的 GRE fieldmap；
- x/y reverse-PE 4-D 输入的 TOPUP→EDDY 完整闭环；
- 无 TOPUP EDDY 的 x/y/z phase encoding；
- 6/12-DOF T1 registration、默认固定 FNIRT 和 nonlinear PPD；
- T1 brain post-mask、m2m tensor 发布、统一 QA、cache/provenance 和可选 FEM smoke。

以下两项不是 v0.3.0 固定运行子集，文档和 CLI 不得声称已实现：

1. Siemens wrapped phase 到 unwrapped rad/s 的 PRELUDE 输入前处理；
2. 官方交互式/可视化 QA 的 `first_ev_for_check.msh` 复刻。

它们不参与 tensor 数值主链。需要这些输入/产物时，调用者必须在项目边界外完成
PRELUDE 或使用官方 QA 工具。项目提供结构化 NIfTI/PNG/JSON QA，但不把它冒充成官方
mesh QA。GRE 的科学参考使用 SimNIBS 4.6 脚本设计意图，即修正官方
`EDDY_CORRECT` 参数计数 off-by-one 后的 intended/patched 分支；不故意复制该 shell bug。

## 2. 第二轮官方流程核对

修复后的默认 raw 流程为：

```text
raw single-shell DWI / pre-fitted tensor
  -> DWI、reverse-PE、fieldmap 的 canonical storage reorientation
  -> raw exact b=0 aligned mean + BET
  -> legacy(+GRE) / EDDY(+TOPUP) / explicit nomoco
  -> correction 后统一 float32 -thr 0
  -> dtifit-compatible WLS（全部已验证 single-shell volumes）
  -> T1 brain/mask + FLIRT 6/12 DOF
  -> default FNIRT + nonlinear PPD，或显式 linear branch
  -> T1 brain post-mask + tensor decomposition
  -> atomic m2m publication + QA + optional FEM smoke
```

逐阶段重新核对后，以下关键顺序与官方一致：

- raw exact `b=0` 与 EDDY 内部 `b<=100` 是两套独立规则；
- raw 负值不在 registration/mask 前提前截断，最终 correction 后才执行 `-thr 0`；
- EDDY WLS 只消费 registered `corrected_dwi`，不消费 scan-space outlier diagnostic；
- EDDY corrected 4-D 写出前乘所有 volume 的联合有效域；
- GRE displacement 与 corrected mask 作为不可拆分合同进入 legacy fitting；
- nonlinear 只在 FLIRT/T1 准备阶段生成所需产物，不再生成后丢弃 affine tensor；
- PPD 后先乘 T1 brain mask，再派生 FA、V1 和 valid mask；
- strict raw fit 不隐式挑选 b1000，而是验证 single-shell 后使用全部 volume；
- 最终 tensor 原子发布到 `m2m_*/DTI_coregT1_tensor.nii.gz` 并记录 SHA-256。

## 4. 具体计算逻辑复核

### 4.1 DTI WLS 与派生图

`strict-fsl` 路径复制 FSL `dtifit` 的关键计算合同：方向单位化、可选九分量
gradient-nonlinearity、两遍 WLS、nonpositive signal log replacement、S0/SSE 和无条件
mask 内派生图。实测本机 FSL 表明：全非正 signal 得到近零 tensor 与 `S0=0.01`；单个
NaN 按 FSL 非正值替换逻辑得到 finite 结果；Inf 会使 FSL 6.0.4 abort。因此 v0.3.0
strict 对前两种输入保持输出兼容，对 Inf 在进入外部崩溃域前显式报错。

正式自动化 A/B 覆盖：

- 单位和非单位 b-vector；
- 3xN 与 Nx3 文件布局；
- grad-dev 九分量；
- positive、all-nonpositive、NaN 和 negative-definite tensor-derived maps；
- tensor、S0、SSE、FA、MD、MO、L1/L2/L3 和 V1/V2/V3。

### 4.2 Motion、field、mask 与坐标

raw ingest 使用不插值的 signed-permutation storage transform，保持 NIfTI qform/sform
和世界几何。PE direction、voxel-basis b-vector、reverse-PE、mask、fieldmap 与 grad-dev
随同一个 transform 更新。legacy direct-b0 看完整时间序列；EDDY 保留 scan-space
outlier-free artifact 仅作诊断，并将 registered output 与联合 mask 绑定。

TOPUP 仍严格限制 x/y，这是 FSL 6.0.4 TOPUP 自身的输入边界；无 TOPUP EDDY 可使用
z/z-。reverse-PE 必须是 4-D，组合入口不再要求用户手工准备 3-D mean 或外部 mask。

### 4.3 T1、FNIRT 与 PPD

默认仍执行官方 nonlinear 分支：FLIRT 只产生 matrix/T1/QA 前置产物，FNIRT schedule
保持 `subsamp=8,4,2,2`、`miter=5,5,5,5`、`lambda=240,120,60,60`，随后用 PPD
重采样/reorient raw-space tensor。strict 模式在 active support 出现 fold、singular
Jacobian 或无法定义的 PPD 时失败，不把 robust zero-fill 冒充成 FSL 数值；robust 模式
需调用者显式选择。所有正常输出在最终 T1 mask 外逐元素为零。

### 4.4 Conductivity 与 FEM

VN、DIR、MC 的 tensor repair、ratio/maximum projection和 intensity correction顺序与
SimNIBS 4.6 `cond_utils` 分支一致，特别是 DIR/MC 的零 tensor 不再参与第一次全局 scale。
主 FEM 仍调用官方 SimNIBS 4.6 SESSION/cond_utils，optimized failure 不会切到 scalar 或
其他 solver。

## 5. 自动化验证结果

本地参考环境：

```text
Python: isolated Python 3.11 SimNIBS reference environment
SimNIBS: 4.6.0
FSL dtifit: /usr/local/fsl/bin/dtifit
FSL version: 6.0.4:ddd0a010
```

正常 JIT 的主测试批次（隔离 MNE 环境问题）：

```text
556 passed, 6 skipped in 38.34s
```

因参考环境旧 MNE/Numba 缓存定位冲突而单独禁用 JIT 的绘图批次：

```text
12 passed in 2.44s
```

合计为 `568 passed, 6 skipped`。合并真实 synthetic TOPUP/EDDY/FNIRT E2E 后，
coverage 为 `12,826/12,826 statements`、`100.00%`。本机 FSL 定向测试在设置
`FSL_DTIFIT=/usr/local/fsl/bin/dtifit` 时通过，包含正常 grad-dev WLS 与
nonpositive/NaN edge-case A/B。TOPUP、EDDY、legacy、fieldmap、T1、FNIRT、PPD、
conductivity、complete DAG、CLI、cache 和 publication 均在主批次内覆盖。

上述证据证明修复后的代码和固定 synthetic/reference 输入；它不把 small-fixture
误差外推成所有扫描仪、所有畸变强度或完整真实被试的 bitwise 相同。真实数据验收仍应
使用同输入、同 single-shell、同 mask、同 precision、同线程边界逐阶段比较。

## 6. 发布判定

v0.3.0 可以作为 correctness/remediation release 发布，条件是版本、wheel/sdist、
coverage、reference assets、CLI 安装和 release metadata 门禁全部通过。发布说明必须：

- 明确 v0.3.0 不是原计划加速版；
- 链接 v0.2.0 原始审计和本报告；
- 只称“SimNIBS 4.6 所需的固定 FSL 子集，运行时无 FSL”；
- 明确 PRELUDE/wrapped phase 与 mesh QA 不在当前子集；
- 不声称 general FSL replacement、全流程通用加速比或未运行平台的数值正确性。
