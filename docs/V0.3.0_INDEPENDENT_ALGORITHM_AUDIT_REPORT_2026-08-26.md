## 1. 执行摘要

### 1.1 最终判定

| 审计问题 | 判定 |
| --- | --- |
| 算法大流程是否相同 | **部分相同**。prefit、nomoco、无 GRE legacy、post-correction `-thr 0`、WLS、T1 FLIRT/FNIRT/PPD 和 T1 post-mask 的主干顺序基本对应；raw QA、无 TOPUP EDDY mask、若干独立 CLI/输入组合不相同。 |
| 具体算法实现是否一致 | **不能认定一致**。GRE+legacy 已确认仿射与位移的组合顺序错误；prefit `fslmaths -tensor_decomp` FA 门限、EDDY shell 边界等也与 FSL 源码不同。 |
| 计算逻辑是否一致 | **不能认定一致**。当前同输入 legacy A/B 的 corrected-DWI relative L2 为 `0.00910`、FA relative L2 为 `0.03730`；完整 TOPUP、EDDY、FNIRT 优化器仍缺当前版本的官方同输入闭环。 |
| v0.3.0 是否可以继续声称“已证明与官方相同” | **不可以**。更准确的表述是：“流程修复已实现、内部合同覆盖较强、部分基础算子经过 FSL 小型 A/B；完整固定子集仍有确认问题和未关闭的数值门禁。” |

### 1.2 最高优先级问题

1. **GRE+legacy 仿射与场位移组合顺序错误**：真实 FSL 最小 A/B 的内部区域
   `max |Δ| = 99.000015`，会改变最终 DWI、tensor 和 conductivity。
2. **raw GRE 接线使用未掩膜 `nodif`**：官方使用 `nodif_brain` 做 MI 配准；当前错误会
   改变场图配准、场、corrected mask 和拟合 support。
3. **缓存不验证输出内容哈希**：可将 m2m tensor 替换成同 shape 的全零 NIfTI，流水线仍
   cache-hit，且 provenance SHA 与真实文件不一致。
4. **无 TOPUP EDDY 依赖外部 mask**：官方在 raw DAG 内部执行 exact-b0 alignment +
   BET；当前 full workflow 强制调用者提供任意外部 mask，因此不是同一输入和计算合同。
5. **当前 legacy 同输入数值 A/B 未通过等价门禁**：流程顺序大体一致不等于优化轨迹和
   最终结果一致；现有偏差没有被 CI 的数值断言捕获。

### 1.3 需要先做的兼容策略决策

官方 SimNIBS 4.6 shell 脚本本身有一个 GRE 参数计数错误：`EDDY_CORRECT` 的注释和唯一
调用把 warp 作为第 5 个参数，但代码使用 `[ $# -gt 5 ]` 才启用 warp。安装版字面执行时
最终 DWI 不会应用 GRE warp。v0.3.0 选择实现修正后的设计意图。

因此后续必须明确两个 oracle：

- `literal-simnibs46`：复现安装版字面行为；
- `intended-gre`：将官方条件修正为能接收第 5 个 warp 参数，再验证预期算法。

建议科学主线保留 `intended-gre`，但必须把它标为对上游缺陷的主动修正，不能再称为
“与安装版逐流程相同”。如确有历史结果复现需求，可另设显式兼容开关；禁止静默选择。

### 2.3 判定术语

- **一致**：代码顺序、输入/输出合同和当前数值证据均支持同一判断；
- **主干一致**：阶段映射相同，但优化轨迹或完整数值闭环尚未证明；
- **确认缺陷**：源码语义已经不同，或有真实同输入 A/B/最小复现；
- **主动差异**：项目有意选择不同策略，必须公开，不一定是科学错误；
- **证据不足**：不能据现有测试声明等价，也不能仅凭缺测试判定实现错误。

## 3. 官方算法流程

官方 SimNIBS 4.6 `dwi2cond` 的 raw-DWI 主流程为：

```text
raw single-shell DWI / pre-fitted tensor
│
├─ prefit
│  └─ copy → fslreorient2std → fslmaths -tensor_decomp
│
└─ raw DWI
   ├─ copy → fslreorient2std；复制 bvals/bvecs
   ├─ exact b==0 volumes
   │  └─ fslsplit/merge → MCFLIRT 6 DOF → Tmean → BET -f 0.2
   ├─ correction 前 DTIFIT WLS
   │  └─ DWIraw_FA + DWIraw_SSE，用于 T1-space QA
   └─ correction branch
      ├─ nomoco
      │  └─ raw DWI + original bvec + 上述 BET mask
      ├─ EDDY without TOPUP
      │  └─ 上述 BET mask → EDDY --repol → rotated bvec
      ├─ TOPUP → EDDY
      │  ├─ reverse 4-D B0 → MCFLIRT 6 DOF → Tmean
      │  ├─ forward/reverse B0 → TOPUP
      │  ├─ 第一幅 corrected B0 → BET -f 0.2
      │  └─ EDDY --topup --repol → rotated bvec
      └─ legacy，optional GRE
         ├─ optional GRE/FUGUE → corrected mask + DWI warp
         ├─ raw 4-D → MCFLIRT 6 DOF → diffusion mean
         ├─ raw 4-D → MCFLIRT 12 DOF + sinc → diffusion mean
         ├─ mean DWI → nodif，FLIRT mutual information
         ├─ 完整 raw 4-D 再做 direct-b0 MCFLIRT 6 DOF
         ├─ 只替换 exact-b0 matrices
         └─ 每个原始 volume 最终一次 sinc resampling

所有 raw 分支
└─ fslmaths DWIforfit -thr 0
   └─ dtifit --wls --sse --save_tensor

T1/head-model
├─ labeling 1..499 → T1 brain mask / masked bias-corrected T1 / rim / weight
├─ primary FLIRT 6 DOF 或 12 DOF
├─ linear: vecreg(matrix)
│  或 nonlinear: FNIRT subsamp=8,4,2,2 → vecreg(warp)
├─ 无条件 T1 brain post-mask
├─ tensor_decomp
├─ 独立 6 DOF corrected FA/SSE QA + raw FA/SSE QA
├─ first_ev_for_check.msh
└─ m2m_<subject>/DTI_coregT1_tensor.nii.gz
```

关键官方位置：

- raw b0、BET 和 raw QA：`dwi2cond.prepro.source.sh:67-100`；
- no-TOPUP/TOPUP EDDY：`dwi2cond.prepro.source.sh:117-143`；
- legacy/GRE 与最终 WLS：`dwi2cond.prepro.source.sh:146-177`；
- legacy 两遍 registration、direct-b0 和最终 sampling：
  `dwi2cond.functions.source.sh:215-315`；
- T1/FNIRT/PPD/post-mask/QA：`dwi2cond.t1reg.source.sh:19-66`。

## 5. 确认问题清单

严重度定义：

- **P0**：可改变正式 DWI/tensor，导致静默错误，或直接阻断“官方等价”结论；
- **P1**：计算边界、输入合同或派生产物与官方不同，可影响特定正式路径；
- **P2**：QA、诊断、低概率退化输入或 artifact 完整性问题；
- **Decision**：必须先冻结兼容目标，不能直接当普通 bug 修。

### D2C-030-001（P0）：GRE fieldmap 与 legacy affine 的组合顺序错误

**状态：确认，可复现，会改变最终数值。**

官方 SimNIBS 在 intended GRE 路径调用：

```text
applywarp ... --premat=<volume matrix> -w DWI_warp --abs --interp=sinc
```

FSL `warpfns` 对 `premat` 与 displacement 的采样关系可写为：

\[
x_{moving}=M^{-1}\left(x_{reference}+d(x_{reference})\right).
\]

当前 [resampling.py:243-261](../src/dwi2cond_xp/preprocessing/resampling.py#L243)
先计算 inverse affine，再直接加未被该 affine 变换的 world displacement：

\[
x_{moving}=M^{-1}x_{reference}+d(x_{reference}).
\]

[legacy.py:536-543](../src/dwi2cond_xp/preprocessing/legacy.py#L536) 对每个 volume
把同一 displacement 直接传入上述采样器。只要 `M` 有旋转、缩放或 shear，两式就不同；
单位矩阵或部分纯平移 fixture 不会暴露问题。

真实 FSL 6.0.4 最小 A/B：

```text
input: 9x9x3 ramp = 100*x + y + 0.01*z
field: constant y=+1 voxel shift
premat: +90 degree rotation around image center

FSL center value:    504.01
current center value:405.01
interior max |delta|:99.000015
```

**影响**：GRE+legacy 的每个 volume 都有独立 motion/eddy affine，当前实现会错误旋转或缩放
位移，进而改变 corrected DWI、mask、WLS tensor、T1 tensor 和 conductivity。

**修复要求**：保持一次正式插值，但必须先在 reference/warp space 形成
`x_reference + d(x)`，再整体应用 inverse per-volume affine；或将 displacement 乘 inverse
affine 的线性部分后再加到 moving coordinate。增加真实 `convertwarp + applywarp --premat`
的旋转、缩放、shear A/B，不接受只测单位 affine。

### D2C-030-002（P0）：raw GRE 入口把未掩膜 `nodif` 传给 MI 配准

**状态：确认，源码接线错误。**

官方先执行 BET，随后将 `nodif_brain` 传入 `APPLY_FMCORR`：

- `dwi2cond.prepro.source.sh:89-91`：生成 `nodif_brain`；
- `dwi2cond.prepro.source.sh:153-159`：调用 `APPLY_FMCORR $RAW_DIR/nodif_brain ...`。

当前代码虽然在
[legacy.py:430-431](../src/dwi2cond_xp/preprocessing/legacy.py#L430) 写出了
`nodif_brain`，但在
[legacy.py:439-446](../src/dwi2cond_xp/preprocessing/legacy.py#L439) 将
`paths["nodif"]` 传给 `run_fieldmap_nifti`。

[fieldmap.py:401-417](../src/dwi2cond_xp/preprocessing/fieldmap.py#L401) 直接使用该数组，
并对 moving/reference 使用全 1 权重做 6 DOF mutual-information FLIRT；`b0_mask` 直到后面的
corrected-mask 合成才使用。因此不能认为内部会自动补回官方 brain-only registration。

**影响**：颅外背景和噪声参与 MI，可能改变 `nodif2FM.mat`、映射后的 field/mask、最终
support 和 tensor。

**修复要求**：raw GRE 入口传 `paths["brain"]`；增加测试捕获传参，并断言 registration
moving image 在 BET mask 外 exact zero。随后重跑正负 PE 两个 full GRE A/B。

### D2C-030-003（P0）：缓存可接受被替换的 m2m tensor

**状态：确认，有静默数据完整性复现。**

根因：

- [pipeline.py:96-157](../src/dwi2cond_xp/preprocessing/pipeline.py#L96) 的 output metadata
  不保存内容 SHA-256；
- [pipeline.py:248-269](../src/dwi2cond_xp/preprocessing/pipeline.py#L248) cache-hit 只检查
  stage fingerprint 和 shape/dtype/finite 等结构；
- publish provenance SHA 只在 action 真正执行时写入；
- [workflow.py:971-974](../src/dwi2cond_xp/preprocessing/workflow.py#L971) 最后只正式验证
  `stages[-1:]`，实际是 `pipeline_qa`，没有重新核对 `publish_tensor`。

最小复现先发布 `(2,2,2,6)` 全 1 tensor，再用同 shape、finite 的全 0 NIfTI 覆盖 m2m
文件，使用新 `PipelineRunner` 和同一个 action 重跑：

```text
first=completed
second=cached
action_calls=1
sha_match=False
numerical_validation=passed
provenance_sha=4fac0f...94531
actual_sha=e3e4d0...74d9f
```

**影响**：m2m tensor 可与 provenance 不一致，后续 conductivity/FEM 仍可能消费被污染文件；
同一问题原则上影响所有缓存 stage。

**修复要求**：

1. 所有普通文件/NIfTI output 在 stage manifest 中保存 SHA-256；
2. cache-hit 重新核对当前文件 SHA，而非只看 shape；
3. publish stage 断言 `source SHA == published SHA == provenance SHA`；
4. formal final validation 显式包含 publish stage；
5. 增加同 shape、同 dtype、finite 但内容不同的 tamper regression。

### D2C-030-004（P0）：无 TOPUP EDDY 没有复现官方内部 b0-mask DAG

**状态：确认，流程和输入合同不同。**

官方所有 raw 分支都先执行 exact-b0 → MCFLIRT 6 DOF → mean → BET `-f 0.2`，no-TOPUP
EDDY 在 `dwi2cond.prepro.source.sh:135-141` 直接使用这个 mask。

当前 [workflow.py:146-151](../src/dwi2cond_xp/preprocessing/workflow.py#L146) 在无 reverse PE
时强制外部 `dwi_brain_mask`，并在
[workflow.py:475-488](../src/dwi2cond_xp/preprocessing/workflow.py#L475) 原样交给 EDDY。
当前只检查它存在且网格匹配，不能证明它是由官方同一 b0 序列、相同 alignment 和 BET
参数得到的 mask。

**影响**：mask 会进入 EDDY cost、outlier detection、output support 和 downstream WLS；
调用者任意外部 mask 会改变计算。

**修复要求**：官方兼容 full workflow 必须内部生成 mask；外部 mask 如需保留，应作为明确
`expert/external-mask` 扩展模式，并在 manifest 标记为非官方流程，不能默认为兼容路径。

### D2C-030-005（P0）：当前 legacy 同输入 A/B 未达到数值等价

**状态：确认，当前 commit 实际重跑。**

本轮用同一个公开 synthetic single-shell fixture，官方 SimNIBS/FSL 固定 1 thread，项目
固定 8 workers，重新运行官方 legacy reference 和当前 `preprocess-legacy`。结果：

| 指标 | 当前值 |
| --- | ---: |

调度；即便如此，后续正式门禁仍必须同时重跑项目 `workers=1` 和 `workers=8`，先证明项目
自身两种调度的数值合同，再把 `workers=1` 与官方串行结果作严格比较。当前结果只用于否定
“等价已经被证明”，不用于把全部偏差归因于某一个内核。

冻结记录还显示：使用同一组 FSL matrices 时，Python resampling relative L2 仅
`7.4296e-7`。因此无 GRE legacy 的主要差异更可能来自 registration optimizer、cost、
边界/trajectory 或 mask，而不是单次 sinc sampler 本身。必须按阶段定位，不能通过放宽最终
tensor 阈值掩盖上游轨迹差异。

**修复要求**：将 b0 alignment、pass1 matrices、pass2 matrices、mean-to-nodif、direct-b0
matrices、corner displacement、corrected DWI、mask、WLS 分阶段入 gate；每个阶段固定输入、
工具版本、线程、精度和预先声明的阈值。

### D2C-030-006（P1）：`fslmaths -tensor_decomp` FA 门限错误复用了 DTIFIT 规则

**状态：确认，真实 FSL A/B。**

[tensor_ops.py:43-59](../src/dwi2cond_xp/preprocessing/tensor_ops.py#L43) 虽区分
`semantics="fslmaths"`，但 FA 仍统一使用 `denominator > 1e-10`。FSL 源码中：

- `dtifit` 确实使用 `1e-10` 分母门限；
- `fslmaths -tensor_decomp` 只以最大特征值 `>0` 决定是否写出，不使用该分母门限。

低幅正定对角 tensor `(1e-6, 5e-7, 2.5e-7)` 的真实 A/B：

```text
current fslmaths semantics FA: 0.0
FSL fslmaths FA:              0.5773502588272095
```

prefit 流程在
[workflow.py:284-302](../src/dwi2cond_xp/preprocessing/workflow.py#L284) 使用该 FA 作为后续
T1 registration 输入，所以这不只是 QA 差异：低幅 tensor 可能改变 registration 和最终
mapped tensor。post-vecreg decomposition 的 derived FA/QA 也会受影响。

**修复要求**：将 `dtifit` 与 `fslmaths` FA 公式的门限逻辑完全分开，增加低幅正定、零、
负定和近退化 tensor 的真实 FSL derivative A/B。

### D2C-030-007（P1）：EDDY 单壳边界把差值恰好 100 当作同壳

**状态：确认，源码语义不同。**

[eddy.py:3014-3020](../src/dwi2cond_xp/preprocessing/eddy.py#L3014) 只在正 b 值范围
`>100` 时拒绝，因此差值恰好 `100` 会被接受。FSL `AreInSameShell` 使用严格
`abs(b1-b2) < 100`。

最小例子 `bvals=[0,900,1000]`：当前把 900/1000 放入同一个 spherical GP，FSL 不认为
它们同壳。常规纯 b1000 数据不受影响，但边界输入会改变 shell grouping 和 EDDY model。

**修复要求**：复用 FSL 的严格 pairwise shell predicate，而不是仅检查全局范围
`<=100`；增加 `99.999/100/100.001` 三个边界测试。

### D2C-030-008（P1）：reverse-PE 在 nomoco/legacy 模式中被接受但完全忽略

**状态：确认，输入路由错误。**

官方一旦收到 reverse-PE 就设置 `DOTOPUP=true`，并强制要求 `--eddy`
（`dwi2cond:242-248`）。当前 `run-pipeline` 全局暴露
`--reverse-phase-encoding`（[cli.py:354](../src/dwi2cond_xp/cli.py#L354)），但只在
`mode==eddy` 时校验和使用。

nomoco/legacy 调用不接收 reverse 文件；该文件却仍被加入 stage input fingerprint
（[workflow.py:566-576](../src/dwi2cond_xp/preprocessing/workflow.py#L566)）。因此存在的
reverse 文件会影响缓存 identity，但算法完全不做 TOPUP。

**修复要求**：拒绝所有 non-EDDY + reverse-PE 组合，并系统检查 dwi-mask、readout、PE、
susceptibility 等参数：任何当前模式不消费的参数都必须 fail-fast，禁止静默忽略。

### D2C-030-009（P1）：`prepare-eddy` 的 z/z- CLI 与实现和文档冲突

### D2C-030-010（P2）：strict-FSL valid mask 与 QA 计数矛盾

**状态：确认，最小复现。**

[nifti_fit.py:131-147](../src/dwi2cond_xp/nifti_fit.py#L131) 的 strict 路径把所有 masked
voxel 标为 valid；这是为了复现 FSL 对全非正和部分 NaN signal 仍写出有限 fit 的行为。
但 [nifti_fit.py:370-378](../src/dwi2cond_xp/nifti_fit.py#L370) 又无条件从
`valid_fitted_voxels` 减去 nonfinite 和 all-nonpositive voxels。

三 voxel 最小复现（正常、全负、部分 NaN）：

```text
valid mask: [1, 1, 1]
valid-mask sum: 3
QA valid_fitted_voxels: 1
QA nonfinite_voxels: 1
QA all_nonpositive_voxels: 1
```

derived maps 使用的是全 1 valid mask，所以 tensor/derived 与 QA 互相矛盾。

**修复要求**：`valid_fitted_voxels` 直接从最终 `valid_output` 计数；异常计数保留为诊断，
不要在 strict 模式中等同于 invalid。robust 模式继续按实际 valid mask 统计。

### D2C-030-011（P2）：官方 raw-DWI pre-correction FA/SSE QA 缺失

**状态：确认，artifact/诊断流程不同。**

官方在任何 correction 之前运行 raw DTIFIT，生成 `DWIraw_FA`、`DWIraw_SSE`
（`dwi2cond.prepro.source.sh:96-100`），T1 阶段再将 raw 与 corrected FA/SSE 分别做 6 DOF

当前 full workflow 只把 correction 后的 `DTI_sse` 传给

`pipeline_qa` 生成 raw/corrected b0/mean，但没有 raw WLS FA/SSE 对照。

**影响**：不直接改变正式 tensor，但丢失官方用于判断 correction 是否改善或破坏数据的关键
诊断边界，也使“完整官方流程”声明不成立。

### D2C-030-012（P1）：standalone nonlinear CLI 允许省略官方必需的 T1 post-mask

**状态：确认；full workflow 正确，standalone 路径不正确。**

### D2C-030-013（P2）：nomoco/legacy stage 未声明下游消费的 bvals/bvecs outputs

nomoco/legacy producer outputs 没有列出 `DWIbvals/DWIbvecs`，但后续 QA 会读取它们。
preprocess cache-hit 后，如果这些未声明文件缺失，只会在更晚的 QA input fingerprint 阶段
失败。producer 的 artifact contract 因而不完整。

**修复要求**：所有 downstream-consumed 文件必须由 producer output contract 明确声明并
参与 cache 内容校验。

### D2C-030-014（P2）：有限输入合同外仍有多个 FSL 边界语义差异

这些问题不是当前 finite single-shell 主路径的首要阻断项，但 `strict-fsl` 命名和后续扩展
需要准确处理：

1. **NaN 下 `fslmaths -thr`**：
   [image_ops.py:35-40](../src/dwi2cond_xp/preprocessing/image_ops.py#L35) 的比较保留 NaN，
   FSL 将 NaN 置零。真实 A/B 输入
   `[NaN,-1,0,1,+Inf,-Inf,2,3]` 时，FSL 输出首项为 0，当前保留 NaN。
2. **全 NaN voxel**：当前 strict fitter显式拒绝；直接 FSL `dtifit` 可完成并给出有限近零
   tensor、`S0=0.01`。若继续把 finite input 作为支持边界，可 fail-fast，但文档不能声称
   此边界与 FSL 完全相同。
3. **FUGUE hole-fill fallback**：
   [fieldmap.py:161-177](../src/dwi2cond_xp/preprocessing/fieldmap.py#L161) 使用
   `np.median`，偶数样本取两个中值平均；FSL percentile 取排序后 `floor(N*0.5)`，即上中位数。
   只影响没有任何有效邻居的退化 hole。
4. **`-mas` helper**：
   [nomoco.py:91-100](../src/dwi2cond_xp/preprocessing/nomoco.py#L91) 使用 `mask>=0.5`，
   FSL `-mas` 使用 `mask>0`。当前调用是 BET binary mask，主流程暂不受影响。

### D2C-030-SCOPE-001：已经明确或应明确的非等价范围

以下差异不应与上面的计算 bug 混在一起，但它们意味着项目不能称为完整复刻官方 CLI/
artifact 合同：

- v0.3.0 只接受已经解缠、已经换算为 rad/s 的 GRE fieldmap；官方还能从 Siemens wrapped
  phase 经 `fsl_prepare_fieldmap/PRELUDE` 准备场图；
- 项目不生成官方 `first_ev_for_check.msh`，也不复刻 FSLeyes/Gmsh 交互检查和 HTML log；
- full workflow 在 FEM disabled 时不要求 `final_tissues.nii.gz` sentinel，官方 T1 path 无条件
  检查它；这不改变 tensor 数值，但 prerequisite contract 不同；
- full raw-GRE workflow 没有官方 `--dontdenoise` 的等价开关，当前固定走默认 median filter；
- 官方 PE 负方向语法是 `-x/-y/-z`，项目公开语法是 `x-/y-/z-`；内部可正确映射，但 CLI
  不是 drop-in compatible；
- 项目保留 intermediates/cache，而官方默认清理 raw/topup/eddy/fieldmap/eddycorr 目录。

这些范围可以继续排除，但必须在 README、INPUT_CONTRACT、METHODS 和 Release notes 中保持
一致，不能用“完整官方工作流”概括。

### D2C-030-DECISION-001：EDDY 默认随机种子是主动策略差异

当前 [eddy.py:3200-3213](../src/dwi2cond_xp/preprocessing/eddy.py#L3200) 和 workflow 默认
`random_seed=1`，以获得可复现结果；内部还把 seed 0 转为 glibc seed 1。官方 SimNIBS 只传
`--repol`，没有 `--initrand`；FSL 默认 seed 0 会按当前时间初始化。

固定 seed 对可复现科学软件是合理选择，但它不等于官方默认调用。建议：

- `compat-literal` 模式复现官方 seed 0/time behavior；
- reproducible 模式明确记录为等价于官方显式 `--initrand=1`；
- reference A/B 双方必须使用相同显式 seed，不比较两个不同随机轨迹。

### D2C-030-DECISION-002：外部 susceptibility field + no-TOPUP EDDY 是项目扩展

官方禁止 GRE fieldmap 与 EDDY 组合，EDDY 的 susceptibility 只来自 TOPUP basename。
当前 no-reverse EDDY 可接受任意 `susceptibility_field`。该能力可以保留，但必须标记为项目
扩展；官方兼容模式应拒绝或要求明确 opt-in。

## 6. 数值与算子审计

### 6.1 已有正证据

本轮在完整 FSL 环境中复跑 8 个真实外部探针：

```text
8 passed in 9.62s
```

覆盖范围：

- `dtifit --wls` + 9-component grad-dev；
- strict nonpositive/partial-NaN 的 tensor/S0/SSE；
- BET synthetic sphere；
- finite fslmaths image operations；
- storage reorientation/cpgeom；
- `fslmaths -tensor_decomp` 的常规幅值 fixture；
- convertwarp topology constraint；
- simple-shear PPD 对真实 `vecreg`。

可以肯定的实现点还包括：

- 六分量顺序为 `[Dxx,Dxy,Dxz,Dyy,Dyz,Dzz]`；
- WLS design、b-vector normalization、两遍 weighted fit、S0/SSE 和 grad-dev 主公式与小型
  FSL fixture 一致；
- MCFLIRT 第一阶段不向最后一个 volume 传播初值的特殊边界与 FSL 源码一致，不应误改；
- TOPUP 固定 `b02b0_nosubsamp.cnf` schedule 对应官方配置；
- FNIRT `subsamp=8,4,2,2` 和固定四层 schedule 对应官方调用；
- PPD simple shear 的真实 vecreg A/B relative L2 `<5e-8`；
- conductivity 的 VN/DIR/MC 公式、修补顺序和主要参数映射与 SimNIBS `cond_utils` 对齐。

这些是局部正证据，不能外推为完整优化器或完整 DAG 等价。

### 6.2 legacy 数值结果如何解释

无 GRE legacy 的 fixed-matrix resampling 很接近 FSL，但优化产生的 matrices、mask 和最终
corrected DWI 有更大差异。这说明下一轮应优先比较优化轨迹，而不是先重写已经通过
fixed-matrix A/B 的 sinc kernel。

建议每个 registration stage 同时记录：

- 初始化矩阵；
- 每个 resolution stage 的 cost、参数和停止原因；
- 最终 FSL matrix；
- 8 个 volume-corner displacement 的 mean/max；
- output support 和 finite mask；
- 同 matrix 下的 resampler A/B。

### 6.3 GRE 数值证据

冻结 fieldmap preparation 小 fixture 本身较接近 FSL：mapped field relative L2 约
`2e-7..7e-7`，corrected b0 relative L2 约 `7e-8`，corrected mask array exact。

但当相同 FSL shift 与 legacy affine 组合时，冻结记录已经出现：

| 指标 | relative L2 |
| --- | ---: |
| corrected DWI | `0.016762173997064877` |
| shared-fitter tensor | `0.01550703628865944` |
| shared-fitter FA | `0.015312330384995503` |

本轮真实 FSL rotation+shift 最小 A/B 又直接证明组合公式错误。因此不能用“fieldmap 单独
prepare 很接近”推导 full GRE branch 正确。

### 6.4 TOPUP、EDDY、FNIRT 当前证据的准确边界

- TOPUP reference JSON 中 `2.98e-8` 是 **FSL coefficient 展开到 dense field** 与 Python
  展开算子的比较，不是当前 Python TOPUP optimizer 最终 field 对 FSL 的完整 A/B。
- EDDY reference JSON 中 `3.8e-7` 是一个 seeded GP hyperparameter 小比较；FSL repol
  对 truth 的误差不是当前候选 EDDY 对 FSL corrected DWI 的比较。
- FNIRT 的 schedule、basis/Hessian/PCG 组件和局部 PPD 有证据，但当前 v0.3.0 修复快照
  没有同输入最终 coefficient/field/warped tensor 的不可跳过 gate。
- FLIRT/MCFLIRT 有 cost oracle、synthetic truth 和历史 JSON，但 tie-breaking、optimizer
  trajectory、stop condition 的最终一致性仍必须由真实 stage A/B 验证。

### 6.5 conductivity/FEM 边界

公式和历史 synthetic sphere 手工 A/B 是积极证据，但当前自动测试对 SESSION、mesh、
TDCSLEADFIELD 和 `cond_utils` 大量使用 fake module。真正调用
`cond_utils.cond2elmdata` 的 `tools/compare_sphere_reference.py` 是手工工具，不在 release
gate 中。v0.3.0 也没有绑定当前 commit 和输出哈希的真实 HCP full FEM 验收。

因此当前可称“实现公式映射与历史手工对照一致”，不能称“v0.3.0 的真实 mesh/FEM 已由
自动化门禁证明等价”。

## 7. 为什么全绿测试没有发现这些问题

### 7.1 frozen reference 数值没有进入断言

[test_preprocessing_reference.py:251-369](../tests/test_preprocessing_reference.py#L251)
主要检查 reference 文件集合、隐私、shape、生成器确定性和 truth outlier。它没有读取并
断言 `synthetic_legacy_reference.json` 中的 corrected-DWI/tensor/FA/SSE 数值，也没有将
TOPUP、EDDY、fieldmap、T1 JSON 中的候选-vs-reference 误差作为 regression gate。

`tools/audit_reference_assets.py` 只做发布安全审计，不重跑候选实现或比较数值。因此
“frozen public evidence”当前是记录，不是不可回归的数值 oracle。

### 7.2 full DAG tests 主要是布线测试

`tests/test_preprocessing_workflow.py` 的完整 DAG cases mock T1 registration、FNIRT、FEM、
QA，并在 EDDY/TOPUP 分支继续 mock EDDY 和 DTI fit；
`tests/test_preprocessing_topup_eddy.py` 也替换 mean、TOPUP、BET 和 EDDY stage。

这些测试能证明 stage 顺序、文件名和参数路由，但不能证明数值闭环。

### 7.3 coverage 不是官方 A/B

`scripts/run_coverage.py` 会执行 candidate synthetic TOPUP、EDDY、FNIRT 路径，但只要求
候选流程完成；它没有在同一个 job 中运行 FSL oracle并比较输出。默认跨平台 CI 也不安装
FSL，8 个外部 probes 会被 skip。100% statement coverage 证明生产分支被执行，不证明
执行的是与 FSL 相同的计算。

### 7.4 现有 direct-FSL 声明过宽

旧 v0.3.0 报告称 direct FSL A/B 覆盖非单位 b-vector、3xN/Nx3、negative-definite
derivatives 和全部派生图。实际：

- FSL fixture 在测试前已经单位化方向，并只写 3xN；
- strict edge-case FSL test 只比较 tensor、S0、SSE；
- 非单位 b-vector 是候选内部自洽测试；
- Nx3 是 loader 测试；
- negative-definite tensor derivative 是候选内部语义测试。

需要补真实 FSL cases，或收窄报告、CHANGELOG 和 Release 文案。

### 7.5 缺少 v0.3.0 当前快照的真实 HCP 闭环

私有 nonlinear run 目录只有 contract manifest，没有完成结果；更早
的 P11 FSL nonlinear harness 记录为 timeout/failed，outputs 为空。8 月 21–23 日的历史
HCP/tensor/FEM 指标早于 v0.3.0 的 57-file 修复，且没有候选 commit 和 output hashes 绑定，
只能作历史诊断，不能作当前 release acceptance。

## 8. 尚未定性的高风险边界

以下项目需要 A/B，不能直接写成 bug，也不能写成已经等价：

1. **TOPUP basename → EDDY**：官方将 field coefficients 与 movement parameters 的
   basename 交给 EDDY；当前组合入口只传 dense `field_hz.nii.gz`。第一 scan movement 在
   固定子集中可能为 reference，但 dense interpolation 是否完全等价尚未证明。
2. **完整 EDDY optimizer**：需要 corrected DWI、movement/EC parameters、rotated bvec、
   outlier map、repol slices 和 downstream tensor 同输入 A/B。
3. **完整 TOPUP optimizer**：需要最终 coefficients、dense field、movement、corrected pair
   和 mask 同输入 A/B，而不只是 coefficient expansion。
4. **完整 FNIRT optimizer**：需要 coefficient field、dense warp、Jacobian、warped FA、PPD
   tensor/V1 和 T1 support A/B。
5. **BET**：当前 Dice `>0.985` 是局部 positive evidence，不代表 surface evolution、
   rasterization 和所有 boundary voxels 相同。
6. **LAPACK/NEWMAT 边界**：重复特征值、病态矩阵、eigenvector sign/tie-breaking 和 BLAS
   reduction 末位必须用固定输入/线程测试，公式相同不足以证明逐值相同。
7. **reverse 3-D B0**：当前组合入口强制 reverse 输入为 4-D；官方 shell 没有显式 4-D
   guard。应先做真实 3-D FSL smoke，再决定支持或明确排除。

## 9. 建议修改顺序

### Phase A：先修会改变正式结果或静默污染数据的问题

1. 冻结 `literal-simnibs46` 与 `intended-gre` 两个 GRE oracle；

### Phase B：收敛 optimizer 数值轨迹

   gate；

## 12. 最终结论

v0.3.0 相比 v0.2.0 确实修复了多个重要流程问题，主代码也包含大量忠实的 FSL 公式、
schedule 和边界实现；因此本报告不是“全部推倒重写”的结论。当前最准确的判断是：

> **主流程骨架已较完整，部分基础算子与官方 FSL 有强局部证据；但是 GRE+legacy、
> no-TOPUP EDDY、prefit tensor decomposition、cache/provenance 和若干输入/QA 合同仍有
> 确认问题，无 GRE legacy 的当前同输入结果也尚未达到可宣称等价的证据水平。完整
> TOPUP、EDDY、FNIRT、conductivity/FEM 仍需在修复后的同一 commit 上建立不可跳过的
> 官方数值闭环。**

下一轮修改应严格按 Phase A → B → C → D 进行。每次只修一个可测问题，保留 reference
后端和独立开关；先做同输入、同 shape、同 precision、同线程的官方 A/B，再比较性能。
