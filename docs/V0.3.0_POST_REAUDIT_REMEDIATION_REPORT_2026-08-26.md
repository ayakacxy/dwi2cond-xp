## 1. 结论

独立复审记录的 `D2C-030-015..041` 共 27 条问题/问题簇已全部完成代码整改和自动化
回归。这里的“27 条”不等于 27 个普通主路径上的核心算法错误：按严重度是 12 条
P0/P1 和 15 条 P2/P3；按互斥的问题性质重分则是 14 条算法/官方分支、10 条数据谱系/
缓存/失败事务，以及 3 条 QA/元数据问题。它们也不是前一轮 `001..014` 的重复修复，
而是把审计范围从已知问题和正常主路径扩展到完整控制流、公开 API、异常分支、产物血缘
和缓存身份后得到的新记录。

整改后可以确认：固定 SimNIBS 4.6 子集的阶段顺序和已列出的 FSL 特殊分支已对齐；本轮
发现的已知错误均有回归门禁。仍不能把这一结论外推成任意 FSL 配置、任意输入或完整
optimizer 的 bitwise equality。特别是 EDDY/FNIRT 独立优化终点仍只声明数值对应，不声明
逐位相同；本轮也没有重新执行完整真实 HCP TOPUP→EDDY→FNIRT→FEM 全链。

## 2. 为什么多轮修复后仍会出现 27 条记录

此前整改的证明边界主要是“已知问题逐项关闭 + 正常输入单元测试 + 若干阶段级 A/B”。
这能证明被覆盖的计算，却不能证明未覆盖的控制分支。此次复审新增了四类此前没有形成
系统门禁的检查：

1. 从 FSL 源码还原 EDDY、TOPUP、MCFLIRT 和 FNIRT 的分支位置及调用顺序，而不是只比
   最终误差；
2. 区分估计期临时数据与正式输出，例如 `--no-repol` 在估计时仍替换 outlier、发布前再
   恢复原始数据；
3. 追踪 raw/corrected DWI、mask、tensor、FEM 动态产物和失败后旧文件的完整血缘；
4. 用 NaN、float/negative mask、oblique affine、薄层 DWI、退化 residual 和 identity
   registration 等判别输入触发正常 fixture 不会覆盖的语义。

因此，问题数量增加说明审计覆盖面扩大，并不说明前一轮关闭的 14 项没有修好。但前一轮
把“已知 14 项关闭”写得过于接近整体完成结论，证据边界不够醒目，这是本次需要纠正的
流程问题。今后每个官方兼容声明必须同时绑定源码控制流、判别 fixture、同输入 A/B 和
失败/缓存合同，不能仅用总测试数或最终 relative L2 代替。

## 4. EDDY 关键闭环

### 4.1 默认 `--repol`

整改后的 26-volume、三 interspersed-b0 fixture 对真实 FSL 6.0.4：

- 双方 final outlier map 逐元素相同，均检出 `(5,8)/(18,7)/(23,10)`；注入的弱异常
  `(11,9)` 均未越过官方检测阈值；
- corrected DWI common-mask relative L2 `0.0015422001`；
- outlier-free scans relative L2 `0.0001109180`；
- movement relative L2 `0.0121336`，全部参数 relative L2 `0.0125511`；
- rotated bvec relative L2 `0.0007533382`。

fixture 由仓库工具的 `--interspersed-b0` 模式确定性生成；输入 SHA-256、两侧命令、输出
哈希和完整指标已持久化到
[`synthetic_eddy_interspersed_b0_reference.json`](../tests/fixtures/reference/synthetic_eddy_interspersed_b0_reference.json)，
不再依赖本机 `/tmp` 目录作为唯一证据。

这些结果证明修复后的控制流和输出已经形成强数值对应，但阈值不是 bitwise-equivalence
声明，剩余差异来自独立 optimizer trajectory。

### 4.2 `--no-repol` 的反直觉证据

四坏片 fixture 上，如果把估计期 replacement 直接保留到正式输出，relative L2 会从约
`0.108` 降到约 `0.003`；仅看最终误差会诱导出错误结论。为区分两种语义，另构造了一个
整卷为零的判别 fixture：FSL no-repol 的对应正式输出卷逐元素为零，证明它在估计期可以
临时替换，但发布前确实调用 `RecycleOutliers()` 恢复原始数据。整改实现采用该官方语义，
没有选择表面误差更小但控制流错误的实现。

## 6. 剩余边界与发布措辞

允许的准确表述是：

> dwi2cond-xp v0.3.0 复现 SimNIBS 4.6 `dwi2cond` 所需固定 FSL 子集；独立复审确认的
> `D2C-030-015..041` 已完成整改，并通过逐项控制流、回归和可用的真实 FSL 阶段级 A/B。

不得外推为：

- 通用 FSL 命令替代；
- 任意 TOPUP/EDDY/FNIRT 配置均受支持；
- EDDY/FNIRT 完整 optimizer 逐位相同；
- 本轮已经重新闭环完整真实 HCP TOPUP→EDDY→FNIRT→FEM；
- 一个 synthetic fixture 的 tolerance 能证明人群级或任意扫描协议等价。

下一版本应先把判别型真实 FSL A/B 作为长期门禁，再开展性能工作；不得以优化为由改变
迭代、停止条件、归约顺序、精度或失败语义。
