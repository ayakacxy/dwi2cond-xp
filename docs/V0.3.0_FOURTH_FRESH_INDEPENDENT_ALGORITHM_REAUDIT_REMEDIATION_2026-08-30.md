## 2. D2C-030-060：legacy matrix 坐标合同

### 2.1 修复

`legacy._register_mcflirt_series()` 继续在已经通过负行列式 FSL A/B 的 local positive
scaled-mm grid 上优化，但不再把其输出直接冒充 FSL matrix。producer 边界显式构造：

```text
C = S_fsl @ inverse(S_local)
M_fsl = C @ M_local @ inverse(C)
```

其中 `S_fsl` 由 `fsl_voxel_to_scaled_mm()` 给出。负行列式时 `C=I`；正行列式时 `C`
是绕最后一个 x voxel 的反射。pass1、pass2、direct-b0 和 mean-DWI-to-nodif 都在进入
composition、保存 `MAT_*`、最终 resampling 和 corrected-bvec 前遵守同一合同。

采用 producer-boundary 共轭而不是直接翻转当前优化器工作数组，是因为真实判别运行显示
后者会改变近似优化器搜索轨迹；严格共轭既保持已有数值轨迹，又在数学上完成 local-to-FSL
坐标变换。

### 2.2 证据

- `test_local_scaled_matrix_to_fsl_matches_nifti_handedness` 固定 x translation 反号和
  negative-det identity control；
- `test_mcflirt_thin_volume_matches_fsl_fix2d_matrices` 对同一组不对称数组分别运行
  `det<0` 与 `det>0` 的真实 FSL MCFLIRT；
- negative-det matrix relative L2=`0.01073097`、max-abs=`0.04755928`；
- positive-det matrix relative L2=`0.01309271`、max-abs=`0.05444754`；
- legacy 与 transforms 聚焦回归为 `33 passed`。

这些结果关闭已确认的 producer-to-consumer handedness 错误，但不宣称所有 3-D optimizer
trajectory 与 MCFLIRT bitwise 相同。

## 3. D2C-030-061：BET inward ray

### 3.1 修复

`brain_mask._fsl_inward_sampling_contract()` 逐句复现 `bet2.cpp`：

1. `dscale=min(xdim, ydim, zdim, 1.0)`；
2. 单独采 1 mm 点并更新 `Imin/Imax`；
3. 单独采 7 mm endpoint 并更新 `Imin`；
4. 按 `dscale` 执行源码中 `gi=2; gi<7` 的中间循环；
5. `gi<3` 的近表面中间点进入 `Imax`；
6. 1 mm 或 7 mm endpoint 越界时，fit force 保持源码初值零。

reference/vectorized 与 optimized/Numba backend 消费同一 distances/maximum-membership
数组，避免两套实现以后再次漂移。

### 3.2 证据

- 1 mm endpoint 暗点反例恢复 `Imin=0`，法向 fit force 由旧实现的正向变为 FSL 的负向；
- 0.5 mm grid 的 1.5 mm 暗点被采到；anisotropic voxel 使用最小 voxel size；
- endpoint 越界返回 invalid-path，reference 和 optimized 都把 fit force 固定为零；
- 真实 FSL sub-mm 暗壳 phantom 最终 mask Dice=`0.99687416`，本地/FSL mask voxel
  数为 `5599/5598`；
- brain-mask 全文件聚焦回归为 `10 passed`。

## 4. D2C-030-062：conductivity eigensystem 模式

### 4.1 修复

standalone `tensor-to-mesh` 新增：

- `--eigensystem-mode stable`（默认）：沿用对实对称 tensor 的 `np.linalg.eigh()`；
- `--eigensystem-mode simnibs46-literal`：逐句执行 SimNIBS 4.6 的 `np.linalg.eig()`、
  real-part、descending sort 和 column reconstruction。

QA JSON 记录 `eigensystem_mode`、每组织最大 basis 正交误差和非正交 basis 数量。literal
模式不会静默正交化或替换病态输出；stable 模式也不会被降级。正式 FEM workflow 仍调用
真实 SimNIBS SESSION，不会被 standalone converter 替换。

### 4.2 证据

固定 `A=I+2qq^T`、eigenvalues `[3,1,1]` 的重复特征值反例中：

- literal eigensystem 与逐句 NumPy/SimNIBS 4.6 公式 array-equal；
- stable conductivity 保持正行列式；
- Linux reference stack 的 literal 输出复现近秩亏结果，并由 QA 记录一个
  nonorthogonal basis；不同 LAPACK 后端可以在退化子空间选择不同但合法的 basis，
  因此跨平台门禁逐平台匹配本机 literal `np.linalg.eig()` 并核对实际 QA，不把 Linux
  特征向量选择误写成平台无关合同；
- conductivity、adapter 和 CLI 聚焦回归为 `55 passed`。

## 5. D2C-030-063：FEM cache fail-closed

`_simnibs_runtime_identity()` 仍记录 distribution RECORD、已检查 Python modules、数值包
和 native library hashes，供诊断和未来完善 closure 使用；但这些候选不能证明 PETSc、
MUMPS、MKL/Pardiso 及动态加载扩展的完整执行闭包。因此：

- 所有真实 FEM stage 的 `cache_safe` 固定为 `false`；
- reason 为 `disabled-unresolved-execution-closure`；
- SimNIBS 未安装时 reason 为 `simnibs-not-installed`；
- 仅无 solver 数值执行的 deterministic dry-run preparation 可缓存。

安装完整/缺模块、四种 solver native discovery 和 reason 字段的聚焦测试均通过。

## 6. D2C-030-064：TOPUP coefficient 与 prefix bundle

coefficient NIfTI 现在写入：

- intent code `2016`（FSL TOPUP cubic spline coefficients）；
- `intent_p1..p3` 为原始 field voxel sizes；
- knot spacing `pixdim`、qform shape translation、qform/sform code 保持官方合同。

在保留 `field_coefficients.nii.gz` 与 `movement_parameters.txt` 的同时，新增
`topup_fieldcoef.nii.gz` 与 `topup_movpar.txt`。因此 `<output>/topup` 可直接作为 FSL

`applytopup --topup=<local-prefix>` 成功读取本地 bundle、产生有限输出。TOPUP artifact、
TOPUP-to-EDDY 和 workflow 合同测试同时通过。
