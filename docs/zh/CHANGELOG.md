## [0.2.0] - 2026-08-24

> **维护性重新发布（2026-08-29）：** 本次仅修正和整理文档及发布元数据，算法源码仍为原始 v0.2 版本。后续审计发现的流程和数值问题在 `v0.3.0` 中作了修复；新部署请使用后续版本，并阅读其验证说明。

### 新增

- 用纯 Python 实现替代运行时的 FSL 预处理依赖，范围为 SimNIBS 4.6 `dwi2cond` 使用的固定功能。FSL 保留为可选本地数值参考工具。
- 新增纯 Python `preprocess-nomoco` 命令：输入规范化、对齐后的 b0 均值、BET 兼容掩膜、非负拟合数据、WLS 张量/FA/SSE、有效性掩膜和结构化 QA。
- 新增纯 Python `preprocess-legacy`：SimNIBS 4.6 两轮 6/12 自由度校正、校正后均值到 nodif 的变换组合、直接 b0 变换、每体积一次最终 sinc 重采样、WLS 拟合、逐体积矩阵及 QA。
- 分别提供逐字节保留 b 向量的 `compat46` 和按有限应变旋转 b 向量的 `corrected` 模式，支持组合预先计算的场位移。
- 新增 `register-t1`：SimNIBS 4.6 自动 6/12 自由度 FA→T1 配准、仿射张量重定向、FA/V1 分解，以及 6 自由度 FA/SSE QA。
- 新增 `prepare-fieldmap`：从已解缠的 rad/s 场图执行固定 SimNIBS 4.6 GRE/FUGUE 流程，包括采样间隔与相位编码参数、6 自由度互信息配准、体素位移、世界坐标毫米位移、校正 b0/掩膜和 QA。
- 新增 `prepare-topup`：SimNIBS 4.6 固定 `b02b0_nosubsamp.cnf` 功能，包括默认源图像重网格、周期三次插值、刚体运动、九级 LM/SCG 优化、场系数、校正 b0、联合掩膜、运动参数和 QA。
- 新增 `prepare-eddy`：固定单壳 EDDY 的五轮运动/二次涡流估计、球面高斯过程预测、预测驱动的 `--repol`、b 向量旋转、壳层对齐、可选 TOPUP 场组合、16 参数输出、迭代记录和 QA。
- 新增固定四级 FNIRT、解析形变/Jacobian 输出，以及按 SimNIBS 4.6 VECREG 流程实现的非线性 PPD 张量重采样与重定向。
- 新增统一工作流 DAG：SHA-256 输入指纹、原子写入阶段记录、缓存复用检查、汇总 QA、资源指标、进度显示，以及 `scalar`/`vn`/`dir`/`mc` FEM 冒烟测试调度。
- 新增支持 Numba 的覆盖率脚本和独立 SimNIBS 4.6 环境检查，用于跨平台 CI 与 tag 发布流程。

### 性能

- 公开 `26x26x18x26` 异常切片样例使用固定种子和八线程，完整 Python EDDY 命令耗时 7.76 秒，FSL 6.0.4 为 9.77 秒（`1.26x`）。四个注入异常切片全部准确检出；掩膜内校正 DWI 与下游张量相对 L2 为 `0.0035352`、`0.0060714`。
- 每个拟合工作进程限制为一个 BLAS 线程，避免进程和线程叠加过量，不改变 HCP 张量、FA、SSE、掩膜和 b0 数组。
- 为已规范化的未压缩 NIfTI 增加检查后的直接 mmap 路径；gzip 或不符合要求的输入仍解码一次，共享一份未压缩中间文件。两条路径在 HCP 样例上逐位相同。
- 八工作进程 HCP `nomoco` 流程：合格 `.nii` mmap 输入为 18.82 秒，`.nii.gz` 为 52.92 秒；较早的本地 SimNIBS 4.6/FSL 6.0.4 参考为 257.30 秒。参考输入的编码形式未固定，因此 `13.67x` 和 `4.86x` 仅供规划参考，不能作为相同输入编码下的正式发布性能结论。
- 将宽度为七的 Hanning-sinc 采样器替换为按输出点并行的 Numba 内核，与保留的参考内核逐位相同；合成 legacy 样例最终重采样从约 8.39 秒降至 0.054 秒。
- 合并 MCFLIRT normcorr 采样热点，保留 FSL float32 乘积的舍入位置和 NumPy 兼容成对求和。Linux 仅对独立 4 mm 体积阶段使用八进程。三次完整合成运行耗时 2.75/2.71/2.87 秒，FSL 为 6.77 秒；矩阵和最终 Python 输出与优化前逐位相同。
- 分析并优化完整 T1 配准流程，并行执行独立 6/12 自由度搜索、张量分量/源掩膜采样、QA 重采样，以及张量 gzip 写出与只读 FA/V1 分解。私有全头进程耗时从 100.90 降至 53.23 秒，FSL 为 233.18 秒。
- 同步推进独立 FLIRT Brent 搜索轨迹，批量构造每轮候选仿射矩阵。公开小型 GRE 场图进程从 6.55–6.88 降至 1.49–1.51 秒；矩阵、七份检查数组和 11,349 次代价计算均与原 Python 路径一致。
- 批量执行两个独立 TOPUP 扫描采样器，以有序 CSR 表示复用正则化乘积，并行展开独立系数体素而不改变每体素 FSL 系数累加顺序。小型样例完整命令中位数为 2.17 秒，FSL 为 4.65 秒；内核已加载时算法中位数为 0.630 秒，五份文件与前一 Python 版本逐位相同。
- 将稠密 TOPUP PCG 循环编译为一次有序 Numba 调用，批量计算五个独立运动交互转置列。公开样例上与保留参考后端逐位相同。九次新进程命令的中位数为 2.12 秒，FSL 6.0.4 为 4.61 秒（`2.17x`）。
- 将四个 TOPUP Gauss–Newton 样条 Hessian 乘积合为一个有序 Numba 装配内核。公开小型反向相位编码样例的三次完整命令耗时为 4.14/4.09/4.18 秒，FSL 6.0.4 为 4.78/4.75/4.66 秒，中位数分别为 4.14 与 4.75 秒。

### 修复

- 低核心数机器上的 Numba 工作线程数限制在运行时可用数量内，同时保留用户请求记录和算法。
- 当 Numba 使用非线程安全的 `workqueue` 后端时，避免并发进入并行区域。在受影响平台，EDDY 将并行放到逐体积串行调用内部，保持相同工作线程预算。
- 生成的 EDDY 样例文本统一使用 LF 换行，并区分同平台确定性检查与跨平台浮点容差检查。
- 恢复 FSL `tensor_decomp` 规则：只有最大张量特征值为正时才输出 FA/特征向量；真实 FA 支持域与 FSL 参考完全一致。
- 修正 FNIRT 移动图像平滑所用的 DTI-FA 体素尺寸，防止并行 Hessian 块共享可变 CSC 结构数组。
- 保持 FNIRT 四级进度单调递增，并在优化结束后继续显示输出、非线性 PPD 和 QA 工作进度。

### 调整

- 在中英文 README 中补充准确的 `vn`、`dir`、`mc` 电导率公式、SimNIBS 特征值限制与原始文献。
- 明确 `mc` 使用直接缩放后局部电导率特征值的几何均值，不是算术均值。
- 在保留全部 `v0.1.0` 张量、电导率、FEM 和先导场接口的同时，将功能从预处理后的张量流程扩展到纯 Python SimNIBS 4.6 `dwi2cond` 固定预处理功能。

### 局限

- 仅实现 SimNIBS 4.6 `dwi2cond` 所用的固定 FSL 功能，不是任意 FSL 命令的通用替代品。
- 不支持需要 PRELUDE 的缠绕相位输入；GRE 分支接受已解缠的 rad/s 场图。
- 阶段耗时只适用于所测版本、样例、主机、工作进程数和缓存状态，不能据此推断任意完整流程的加速比。

## [0.1.0] - 2026-08-21

### 新增

- 纯 Python 单壳两轮 WLS DTI 拟合，可选 HCP/FSL 梯度非线性校正及体素级进度。
- FA、MD、MO、特征值/特征向量、S0、SSE、有效性掩膜和 QA 输出。
- 使用明确仿射矩阵将张量重采样到 T1，并进行有限应变重定向。
- 兼容 SimNIBS 的 `vn`、`dir`、`mc` 电导率转换。
- SimNIBS 4.6 固定电极配置 FEM 调度，默认使用 Pardiso。
- 严格限定于白质/灰质/脑脊液的被试空间电场输出，以及四模式 NIfTI 对比图。
- 先导场配置、HDF5→NPY/JSON 检查和导出格式。
- 对包内全部 1,644 条可执行语句进行测试，覆盖 DTI/NIfTI 拟合、多进程、张量转换与配准、SimNIBS 适配、仿真、先导场、CLI 分发、可视化、错误处理及本地 FSL 数值比较。

### 调整

- 将 CI、SimNIBS 集成和发布覆盖率要求从 75% 提高到 100%。
- 重写中英文 README，补充发布、安全、验证、性能和科学适用范围说明。

### 局限

- 当时最终跨平台 QA/DAG 和隔离安装验收仍在进行，不依赖 FSL 的完整预处理替代功能尚未发布。
- 完整被试的全电极先导场运行不在本版本验证范围内。
