## [0.4.0] - 2026-10-14

### 概述

本次先修复坐标和张量方向问题，再减少同一
工作流中的重复计算与大数组开销。迁移和设备选择见[发布说明](https://github.com/ayakacxy/dwi2cond-xp/blob/v0.4.0/docs/zh/RELEASE_NOTES_v0.4.0.md)。

### 修复

- 修复 Windows 下 NIfTI 写回原文件或同一文件硬链接时的失败。
- legacy 在最终运动变换所属的 FSL 基底中旋转梯度，默认改为 `--bvec-mode corrected`。
  存储轴重排同步转换 b 向量、张量分量及列主序梯度偏差矩阵
  （`--component-mode physical`）。
- 修正正行列式存储下 GRE/TOPUP 的相位编码符号和 EDDY 的放射学坐标转换；
  输出恢复图像存储坐标，避免对运动参数或 FSL 梯度重复反射。
- 仿射和稠密位移的 FSL 采样独立使用 NIfTI header `pixdim`，与世界 affine 区分。
  不能同时表达两种尺度的 raw/FNIRT 路径明确拒绝尺度不一致。
- PPD 与折叠/近奇异 QA 使用目标网格的物理导数（`--jacobian-mode physical`），
  包括非 1 mm 目标体素。
- 张量物理基底分别归一化 affine 的空间列，拒绝剪切；正式 SimNIBS FEM/先导场
  实例应用所选的稳定对称特征分解与基底模式，不修改 SimNIBS 本身。
- 在工作网格上检查已准备的外部 Hz 场图，最终 QA 通过后才向 m2m 发布张量及来源记录。

### 调整

- 原始准备和 WLS 复用不变的计算，流式读取满足条件的 float32 gzip 输入，减少
  体积、坐标和有效性数组复制，保留独立的原始 QA 拟合与正式拟合。T1 主仿射和刚性
  QA 配准共享只读金字塔，细层相关比采用自适应 FP64 分块统计。
- FNIRT 共享样条支持域遍历，省去未使用的基底和仿射场临时数组；LM 工作矩阵使用
  CSR，保留原 CPU PCG 求解器、迭代、阻尼、容差及停止规则。
- PPD 和张量分解采用有界空间分块，省去未使用的解析 Jacobian 和方向，及时释放
  已完成的位移场。QA 和 NIfTI 写出减少重复读取与全体积临时数组，保留全部值的
  有限性检查、内容哈希和科学 QA。
- 新增显式 CUDA 后端：`--fnirt-device cuda` 用于 FP64 样条 Hessian 组装，
  `--ppd-device cuda` 用于采样、Jacobian、特征分解与旋转。默认仍为 CPU，
  不需要导入 CUDA/CuPy。PPD 保留 float32 采样检查点和 FP64 矩阵运算，LM/PCG
  仍在 CPU 执行；CUDA 失败会终止运行，不静默切换设备。

### 验证与性能实测

- 本地 960 个独立用例通过，无跳过，覆盖 15,364/15,364 条语句（100.00%），
  并执行真实合成 TOPUP/EDDY/FNIRT 三条 CLI。各批次与数值检查见
  [验证记录](https://github.com/ayakacxy/dwi2cond-xp/blob/v0.4.0/docs/zh/VALIDATION.md)。
- 同一 Linux HCP 单壳输入、八个物理核心、热缓存完整运行：CPU 为
  **205.452 秒 / 主机 RSS 6.498 GiB**，GPU 为 **163.342 秒 / 主机 RSS 6.723 GiB**，
  GPU 分配峰值为 **8.834 GiB**。FEM 关闭。
- 公开 v0.3.0 的 CPU 完整运行为 **564.406 秒 / 25.469 GiB**，当前 CPU/GPU 的
  观察耗时比分别为 **2.747× / 3.455×**。SimNIBS 4.6/FSL 6.0.4 官方子脚本使用
  原生梯度非线性校正，为 **1290.073 秒 / 3.794 GiB**，观察耗时比为
  **6.279× / 7.898×**。FSL 写出的项目诊断较少，且经常只使用一个核心；这些是
  实际流程比较，不是纯硬件加速或最终 FSL 数值等价声明。
- CPU/GPU 的 64 份数值产物中，61 份逐字节相同。脑内张量相对 L2 为 `1.8693e-9`，
  最终 FA 最大绝对差为 `8.7172e-7`，健康谱 V1 轴向夹角 P99 为 `1.2074e-6` 度。
  几何、掩膜、FNIRT 位移场/系数及 LM 记录一致。[基准记录](https://github.com/ayakacxy/dwi2cond-xp/blob/v0.4.0/docs/zh/BENCHMARKS.md)列出
  计时范围、阶段耗时、数值检查及限制。

### 兼容性

新的 corrected/physical 默认值会有意改变受影响的输出。显式 `--bvec-mode compat46`
及分量、Jacobian、基底、特征分解的 `simnibs46-literal` 模式仍可用于上游对照；
它们不会关闭 GRE/TOPUP/EDDY 或发布顺序修复。GPU 证据限于已记录的
Linux/RTX 2080 Ti 输入，本次没有新增其他平台 GPU 或完整 FEM 验证结论。

## [0.3.0] - 2026-08-30

### 概述

`v0.3.0` 是完成正确性修复的稳定版本。它保留 `v0.2.0` 引入的 SimNIBS 4.6 `dwi2cond` 固定支持范围，并修正独立源码审计和同输入对照中发现的处理阶段间数据传递、数值边缘情况、输出发布事务及运行环境身份检查问题。

### 主要变化

- 修正原始 DWI 和预拟合张量流程，包括 EDDY/TOPUP 产物的来源关系、最终掩膜与阈值处理顺序、GRE 位移组合、旧版 MCFLIRT 控制流程、严格单壳拟合，以及仿射和非线性 DTI→T1 输出发布。
- 恢复 SimNIBS/FSL 的处理顺序，涉及张量分解、非线性 PPD 掩膜与重定向、b 向量归一化、全零张量的 DIR/MC 校准，以及派生 FA、V1 和有效性输出。
- 按 FSL 6.0.4/NewNifti 的 float32 Gram–Schmidt、带符号置换和严格平局判定规则实现方向选择，并加入大倾斜角及全部带符号置换的回归用例。
- 将已验证的非线性数值环境固定为 NumPy 2.3.0 和 Numba 0.64.0；扩展缓存匹配信息，覆盖拟合模式、科学输入、实现模块、数值软件包、SimNIBS 安装记录和原生求解器库。
- 使工作流和 FEM 输出在发布失败时保持一致：失败的重试保留诊断清单，不会覆盖最近一次已通过检查的张量、m2m 产物或仿真结果。
- 对非零奇异张量，VN 默认明确报错，取代此前的静默处理；用户可显式启用有界正则化，并在 QA 中记录。
- 新增完整的原始数据与预拟合张量流程入口、SHA-256 来源记录、结构化 QA、经检查的缓存复用、进度与资源报告，以及 `scalar`/`vn`/`dir`/`mc` SimNIBS 仿真组织功能。
- 修复旧版矩阵在正行列式情况下的不一致：所有本地配准模块先转换到 FSL 放射学 scaled-mm 坐标约定，再进行矩阵组合、保存、重采样和 b 向量校正。
- 将 BET2 的 1 mm 和 7 mm 端点、亚毫米 `dscale` 循环、近表面最大值采样，以及越界时零作用力行为纳入参考与优化实现共用的采样规则。
- 默认继续使用稳定的对称电导率特征分解，并新增显式的 `simnibs46-literal` 特征系统模式，用于重复特征值情况下的精确兼容测试，且记录到 QA。
- 在能够完整记录动态加载的 Python 及原生求解器依赖之前，禁用真实 SimNIBS FEM 计算的缓存命中；确定性的 dry-run 准备过程仍可缓存。
- 新增官方 TOPUP 三次样条 intent 参数，以及 FSL 可读取的 `topup_fieldcoef`/`topup_movpar` 同前缀文件组，同时保留项目已有的产物名称。

### 验证

- 配置全部真实 FSL 探针后，最终仓库检查为 `666 passed`，无跳过项。独立覆盖率检查同样得到 `666 passed`，电极配置批次为 `12 passed`，覆盖全部 `13,663/13,663` 条生产代码语句；包含真实执行的合成 TOPUP、EDDY、FNIRT 命令行路径。
- 最终修复之前收集的阶段性参考结果包括：HCP WLS 张量相对 FSL 6.0.4 的 L2 误差为 `4.18e-6`；本地合成球形网格电导率最大绝对误差，`vn` 为 `0`、`dir`/`mc` 为 `2.22e-16`；私有 T1/T2 CHARM 头模型上的 C3/C4 FEM 四模式仿真均生成有限且严格按组织掩膜保留的向量场。这些是各版本保留的实验记录，不代表对本次发布重新运行了完整流程。
- 最终标签通过 Ubuntu、macOS、Windows CI，以及软件包构建、依赖与元数据检查、CodeQL、OpenSSF Scorecard、发布校验和、CycloneDX SBOM、构建来源证明和隔离 wheel 安装检查。

### 支持范围

- 本项目独立实现 SimNIBS 4.6 `dwi2cond` 使用的固定 FSL 行为，不是通用 FSL 命令替代品。FSL 仅作为可选数值参考，不是运行时依赖。
- 严格张量拟合仅支持单壳数据。不支持需要 PRELUDE 的缠绕相位或任意 TOPUP/EDDY/FNIRT 配置；GRE 路径接受已解缠、单位为弧度每秒的场图。
- 验证结果适用于已测试的处理阶段与工作流范围，不代表迭代 EDDY/FNIRT 对任意输入逐位一致，也不提供通用的完整流程加速比。单名私有 HCP 被试的结果不能外推到人群，现有验证也不包含完整全电极先导场计算。

## [0.2.0] - 2026-08-24

### 概述

`v0.2.0` 在最初的张量与电导率工具包基础上，新增纯 Python 实现，覆盖 SimNIBS 4.6 `dwi2cond` 调用的固定预处理与配准子集，运行时无需 FSL。

### 主要变化

- 新增 `nomoco` 和旧版原始 DWI 预处理、加权张量拟合、梯度非线性支持、对齐后的 b0 与掩膜生成，并显式区分 `compat46` 和有限应变校正的 b 向量模式。
- 新增固定 GRE/FUGUE、TOPUP 和单壳 EDDY `--repol` 路径，包括可选的 TOPUP 到 EDDY 场组合，以及结构化的中间质量检查。
- 新增自动 6/12 自由度仿射配准、四级 FNIRT、非线性 PPD 张量重采样与重定向，以及标准张量、FA、V1 输出发布。
- 新增统一工作流，包含输入指纹、原子写入清单、经过检查的缓存复用、进度与资源统计、电导率与 FEM 冒烟测试，同时保留 `v0.1.0` 接口。

### 验证与实测结果

- Linux 发布检查为 `535 passed, 7 skipped`，覆盖全部 `12,443/12,443` 条可执行语句。Ubuntu、macOS、Windows 同样通过 100% 覆盖率要求；可选外部参考测试在缺少前置条件时明确显示跳过。
- 公开的 `26x26x18x26` 人工注入异常值测试中，完整八线程 EDDY 命令耗时 `7.76 s`，FSL 6.0.4 为 `9.77 s`。四个注入异常的切片均被检出；掩膜内校正 DWI 和下游张量的相对 L2 误差分别为 `0.0035352` 和 `0.0060714`。
- 公开的 `16x14x12` 反向相位编码测试中，完整 TOPUP 命令耗时中位数为：dwi2cond-xp `2.12 s`，FSL 6.0.4 `4.61 s`。这些数值仅对应所述测试数据和计时范围，不代表完整工作流的加速。

### 限制

- 固定子集不支持需要 PRELUDE 的缠绕相位或任意 FSL 命令配置；严格拟合仍限于单壳数据。
- 后续源码与控制流程审计在 `v0.2.0` 中发现了重要的工作流组合和数值缺陷；`v0.3.0` 针对此类问题进行了修复。新部署应使用当前稳定版本。

## [0.1.0] - 2026-08-21

### 概述

`v0.1.0` 建立了从 DTI 到电导率及 SimNIBS 集成的基础，输入为已预处理的单壳 DWI 或用户提供的六分量扩散张量。

### 主要变化

- 新增纯 Python 两遍 WLS DTI 拟合，支持可选的 HCP/FSL 梯度非线性校正，输出张量、FA、MD、MO、特征值、特征向量、S0、SSE、有效掩膜和 QA 报告。
- 新增到 T1 的仿射张量重采样与有限应变重定向，以及兼容 SimNIBS 的 `vn`、`dir`、`mc` 电导率转换。
- 新增固定电极配置的 SimNIBS 4.6 FEM、严格限制在白质/灰质/脑脊液内的向量电场输出、可视化，以及先导场检查和导出接口。

### 验证与实测结果

- 发布测试为 `144 passed`，覆盖全部 `1,644/1,644` 条可执行语句。
- 对一份私有 HCP b0+b1000 输入，与 FSL 6.0.4 的 WLS 加梯度非线性校正比较，张量相对 L2 误差为 `4.18e-6`。在同一服务器和拟合计时范围内，16 个 worker 的 Python 拟合耗时 `9.76 s`，FSL 为 `108.23 s`。这是 DTI 拟合结果，不代表完整工作流表现。
- 合成网格上与 SimNIBS 4.6 比较，电导率最大绝对误差 `vn` 为 `0`、`dir`/`mc` 为 `2.22e-16`。真实 C3→C4、1 mA FEM 在 `scalar`、`vn`、`dir`、`mc` 四模式下均完成，生成有限且严格按组织掩膜保留的向量场。

### 限制

- 本版本要求在外部完成原始 DWI 的运动与畸变校正，以及自动仿射和非线性配准。
- 发布时的完整流程验证不包含真实被试的完整全电极先导场计算。
