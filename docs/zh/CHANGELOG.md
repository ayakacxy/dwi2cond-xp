## [0.1.0] - 2026-08-21

首次公开发布，将外部预处理后的扩散 MRI 用于 SimNIBS 4.6 的标量或各向异性电导率仿真。

### 新增功能

- 纯 Python 单壳 DTI 拟合，采用两次求解的 WLS，支持可选 HCP/FSL 梯度非线性校正及体素处理进度显示。
- 输出张量、FA、MD、MO、L1-L3、V1-V3、S0、SSE、有效掩膜和 QA 报告。
- 使用用户提供的仿射矩阵将张量映射至 T1 网格，并进行有限应变重定向。
- 与 SimNIBS 兼容的 `vn`、`dir`、`mc` 电导率转换；`dir` 和 `mc` 在所选各向异性组织之间共用一个全局校准系数。
- SimNIBS 4.6 固定电极配置的 FEM，默认使用 Pardiso。
- 输出电场严格限于白质、灰质和脑脊液，并提供四模式 NIfTI 对比图。
- 先导场配置，以及 HDF5 到 NPY/JSON 的检查与导出。
- 发布环境中全部 1,644 条可执行包语句均被测试覆盖，包括可选的本机 FSL 参考对照。

### 验证范围

- 已记录的 HCP DTI、合成球形网格电导率和四模式固定电极配置 FEM 结果仅适用于文档所述输入与步骤。
- `v0.1.0` 不包含原始 DWI 的运动、涡流、磁敏感性校正、自动仿射或非线性配准，以及非线性 PPD 张量重定向。
- 本版本的验证记录不包含真实被试完整的全电极先导场计算。
