`v0.4.0` 是 2026-10-14 的稳定版本，包含坐标/方向修复和组件提速，并完成了
与公开 v0.3.0 wheel、官方 FSL 子脚本的 CPU/GPU 完整对照。
迁移方式见[v0.4.0 发布说明](RELEASE_NOTES_v0.4.0.md)，实测范围见[性能测试](BENCHMARKS.md)。

## 稳定版本的范围

项目用纯 Python 实现 SimNIBS 4.6 `dwi2cond` 使用的固定子集：原始 DWI 或预拟合
单壳张量流程，legacy/GRE/TOPUP/EDDY 预处理，仿射与非线性 DTI→T1 配准，PPD 张量
重定向，`scalar`/`vn`/`dir`/`mc` 电导率，以及 SimNIBS FEM 和先导场接口。
FSL 仅用于可选的数值比较，不是运行依赖。

维护内容包括已确认的正确性修复、依赖与平台兼容、打包和安全更新、文档修订。稳定 tag
通常不变。若明确授权修订历史文档，应保留原 tag 对象和提交的备份及项目记录，保持
算法源码不变，重建发布文件，并记录可核验的恢复关系。

## 如何使用历史结果

单纯整理文档无需重复已完成的实验。历史结果应对应明确的源码版本、输入、环境、指标和
计时或数值比较范围。只有新结论依赖改变后的实现/环境，原证据无法重建，或发现影响
结论的不一致时，才需要重跑。

因此，`v0.1.0` 至 `v0.3.0` 的历史仍以各版已完成的验证为依据。具体输入上的数值与
耗时见[基准记录](BENCHMARKS.md)，其结果不能推广为所有硬件或输入上的保证。

## v0.4.0 已完成工作

已完成的修复包括 legacy 梯度、存储轴分量、GRE/TOPUP/EDDY 手性、物理 PPD 导数、
电导率基底及 QA 成功后发布。性能优化减少原始准备、T1 配准、FNIRT、PPD、QA 和
写出过程中的重复工作及大数组开销。默认使用 CPU；显式 CUDA 选项加速 FP64 Hessian
组装和 PPD，LM/PCG 仍在 CPU 上运行。

完整同输入对照中，CPU 为205.452秒，GPU为163.342秒，公开 v0.3.0 为564.406秒，
FSL为1290.073秒。这些是同一 Linux 输入、FEM关闭、缓存预热后的单次观察，输出范围和
核心使用方式有差异。各阶段数值检查和 CPU/GPU 完整产物检查分别记录；四方表不推导
多次运行的离散程度或通用速度保证。

进一步内存优化已按用户要求停止，最终源码保留先前经过验证的速度和数值行为。
历史 v0.3.0 测试数和覆盖率仍归属该版本；v0.4.0 的验证单独记录在发布说明中。

## 已知限制

- 项目只实现 SimNIBS 4.6 `dwi2cond` 使用的固定 FSL 子集，不覆盖通用 FSL 命令。
- 严格张量拟合限于单壳；需 PRELUDE 的缠绕相位，以及任意 TOPUP/EDDY/FNIRT 配置
  不在支持范围内。
- 性能结果只适用于记录中的具体输入与计时范围，没有通用的完整流程加速倍数。
