## 已预处理的 DWI

DWI 应已完成适合其采集方式的运动、涡流和磁敏感性/EPI 畸变校正；b 向量应随运动校正同步旋转。DWI、脑掩膜、b 值和 b 向量必须对应同一组、相同顺序的数据。

DTI 拟合使用 b=0 体积和一个非零壳层。多壳数据必须先用 `select-shell` 或其他可追溯的步骤选出所需壳层。程序不会直接把全部非零壳层合并拟合为单张量。

可选的 `grad_dev` NIfTI 使用 HCP/FSL 的九分量排列，其空间尺寸和仿射矩阵必须与 DWI 一致。

## 扩散张量

张量 NIfTI 的形状为 `(X,Y,Z,6)`，最后一维依次为 `Dxx,Dxy,Dxz,Dyy,Dyz,Dzz`。数值必须有限。建议保留拟合阶段生成的有效体素掩膜；若张量来自其他软件，应同时提供相应掩膜。

## 与 T1 对齐

`register-tensor` 应用用户提供的 4×4 仿射矩阵，将输入世界坐标映射到参考世界坐标，并进行有限应变张量重定向。它不估计配准矩阵。只有外部预处理已经将两者对齐到同一世界坐标系时，才可显式指定 `--assume-aligned`。

`v0.1.0` 不实现自动 FLIRT/FNIRT 配准、非线性形变、局部雅可比矩阵或 PPD 重定向。DWI 与 T1 来自同一被试并不意味着它们已经对齐：运动、畸变、分辨率、方向及扫描仪坐标均可能不同。

## CHARM 掩膜与输出

兼容的脑掩膜沿用 SimNIBS `dwi2cond` 的标签范围 1–499。最终张量写入 T1 网格，并保存为 `m2m_<subject>/DTI_coregT1_tensor.nii.gz`，供 SimNIBS 读取。

尺寸、仿射矩阵、有限值、有效掩膜或来源记录检查失败时，程序会明确报错。各向异性仿真不会在输入异常时自动改用标量电导率。
