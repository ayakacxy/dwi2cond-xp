# 计算方法

[English](../en/METHODS.md) | [简体中文](../zh/METHODS.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

流程采用 SimNIBS 4.6 的预处理和张量到电导率步骤。图像处理、拟合和配准使用 Python 实现，FEM 使用已安装的 SimNIBS 求解器。[输入说明](INPUTS.md)列出数据与坐标要求，[使用示例](USAGE.md)提供命令。

## 固定预处理配置

| 路径 | 处理步骤 |
| --- | --- |
| `nomoco` | 对齐 b0 以生成参考和掩膜；拟合扩散体积，不施加运动或畸变校正 |
| `legacy` | 两轮 6/12 自由度运动/涡流校正、组合变换，每个原始体积最终执行一次 sinc 插值 |
| GRE | 对已解缠 rad/s 场图执行固定 FLIRT/FUGUE 组合 |
| TOPUP | 固定九层 `b02b0_nosubsamp.cnf` 调度 |
| EDDY | 固定五轮单壳层运动/二次涡流模型、球面 GP 预测、切片替换、梯度旋转和可选 TOPUP 场 |

存储重定向默认同时变换图像轴、b 向量、压缩张量和列优先梯度偏差矩阵。Legacy 运动旋转在 FSL scaled-mm 基底中使用最终变换。GRE、TOPUP 和 EDDY 在不同图像手性下统一采用内部放射学坐标；PE 参数也指这些内部轴。

## DTI 拟合

模型使用 b=0 和一个非零壳层。独立拟合支持显式选壳及近零 b 值阈值；原始数据流程使用精确 b=0。

两次加权最小二乘求解均以正观测信号的平方为权重，非正观测的权重为 1。第一次估计 S0，第二次取对数前将信号下限设为 S0 的 1%，权重保持不变。可选梯度非线性数据逐体素修正方向和 b 值。

两次求解复用 float64 法方程矩阵。最大绝对分量不超过 `1e-8 mm²/s` 的张量使用参考收缩重新计算，以保持近零处尺度无关 FA 的稳定性。输出包含张量、FA、MD、MO、L1–L3、V1–V3、S0、SSE 和有效性信息。

`strict-fsl` 使用已验证的 FSL 异常值处理。`robust` 排除包含非有限信号或没有正信号的体素，写入零张量并记录 QA。拟合不施加半正定约束，因此可能产生负特征值或大于一的 FA。

## 张量映射

仿射映射使用输入世界坐标到参考世界坐标的变换及逆向体素采样，在源和目标 FSL scaled-mm 基底中提取正交极分解因子，以 `R D R^T` 重定向张量。自动 T1 配准采用固定 6/12 自由度 FLIRT 调度，并独立进行刚体 QA 配准。

非线性配准采用固定四层 FNIRT 调度和主方向保持（PPD）。物理 PPD 按目标体素尺寸对毫米位移求导，张量旋转和折叠 QA 使用同一物理 Jacobian。需要时另行保留 FNIRT 解析非线性 Jacobian。

采样使用头字段 `pixdim`，独立于世界仿射。仿射和稠密形变路径支持二者尺度不同；原始预处理和 FNIRT 要求尺度一致。物理电导率基底分别去除仿射列尺度并检查正交性，支持斜置、非等尺寸体素，拒绝剪切。

### CPU 执行和内存

准备阶段将适用的 float32 gzip 输入流式写入共享未压缩工作图像。WLS 复用不变矩阵；T1 仿射与刚体 QA 共享只读金字塔，各自保持独立优化器。精细相关比层使用自适应 FP64 分块统计。

FNIRT 共享样条支撑遍历和全局投影，以 CSR 保存 LM 工作 Hessian，沿用 CPU PCG。迭代上限、阻尼和停止规则保持不变。PPD 和张量分解按有限大小批次执行，并包含批次边界所需的相邻位移采样。QA 独立分块检查存储结果，减少大数组的重复读取；写出失败时保留上一次有效文件。

### 可选 CUDA

`--fnirt-device cuda` 通过 Numba CUDA 以 FP64 累加装配样条 Hessian，同一层内复用样条几何。LM 和 PCG 仍在 CPU 执行，此后端不需要 CuPy。

`--ppd-device cuda` 通过 CuPy 分批执行张量采样、Jacobian、特征分解和旋转，源张量在批次间驻留设备。保留 float32 采样和位移差分检查点，Jacobian 与矩阵运算使用 float64。派生图和 NIfTI 写出仍在 CPU 完成。

两个选项默认均为 `cpu`。已有 CUDA 测量环境为 Linux、RTX 2080 Ti、CuPy 14.2.0 和 CUDA 12.8。设备选择会写入阶段参数和 QA；显式请求的 CUDA 后端无法运行时会报错。实际测量见[性能记录](BENCHMARKS.md)。

## 流程与来源记录

阶段记录包含参数、软件版本、输入摘要、耗时、资源使用和 QA。复用缓存前检查输出结构与内容；命中缓存会标记为复用。原始 QA 拟合、最终非负阈值拟合和存储结果的最终 QA 分别执行。

QA 通过后，最终张量及来源记录才发布到 m2m；可恢复的发布错误会还原已接受的文件对。外部场 QA 检查工作网格上准备后的场。

真实 FEM 不复用执行缓存，因为记录尚未覆盖动态加载的全部求解器依赖；确定性的 dry-run 准备可缓存。求解器记录包含检查过的 SimNIBS 模块、数值依赖版本和原生库摘要。

## 电导率映射

张量按所选物理基底和特征系统采样到网格单元。`vn` 归一化局部行列式；`dir` 在各向异性组织间拟合一个全局尺度；`mc` 使用同一尺度，再将每个局部张量变为各向同性。各模式均应用其特征值、电导率和各向异性安全规则。

默认对称 `eigh` 特征系统提供正交基底，字面 `eig` 行为用于上游对照。正式 FEM 和先导场实例通过实例局部的电导率适配器接收设置，已安装的 SimNIBS 模块保持原样。

非零奇异 VN 张量默认报错，除非显式请求正则化。全零的各向异性 `dir`/`mc` 组织无法定义全局标定尺度；不标定选项有独立的安全处理。公式和参考文献见[电导率模型](CONDUCTIVITY.md)。
