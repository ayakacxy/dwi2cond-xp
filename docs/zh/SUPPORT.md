# 获取帮助

[English](../en/SUPPORT.md) | [简体中文](../zh/SUPPORT.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

安装和使用问题请在 [GitHub Discussions](https://github.com/ayakacxy/dwi2cond-xp/discussions) 中提出。软件缺陷、性能问题和功能建议请使用仓库的 [issue 模板](https://github.com/ayakacxy/dwi2cond-xp/issues/new/choose)。

报告中请提供软件包版本、操作系统、Python 和 SimNIBS 版本、所选预处理与配准模式、工作进程数、完整命令及报错信息。小规模合成示例有助于复现问题。性能报告还需说明图像尺寸、缓存状态和计时包含的步骤。

分享日志或 QA 文件前，移除患者数据、凭据和私有路径。欢迎使用英文或中文报告问题；安全问题请按[安全政策](SECURITY.md)提交。

超出本软件包范围的 SimNIBS 或 FSL 行为，请向相应上游项目咨询。
