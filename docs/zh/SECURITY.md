# 安全政策

[English](../en/SECURITY.md) | [简体中文](../zh/SECURITY.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

安全修复面向最新 tag 版本和 `main` 分支。如仓库启用了 GitHub 私密漏洞报告，请通过该功能报告漏洞。未修复的安全问题不应公开发在 issue 中。

不要附上可识别身份的医学影像、HCP 受控访问文件、被试标识、令牌、环境文件，或暴露私有基础设施的绝对路径。优先提供最小合成复现样例。

本项目是研究软件，不是医疗器械，也不提供临床建议。科学分歧或异常仿真结果通常属于使用支持问题；只有源于安全缺陷时才按漏洞处理。
