安全修复面向最新 tag 和 `main`。请优先通过 GitHub 私密漏洞报告功能反馈漏洞，
不要为尚未修复的安全问题创建公开 issue。

不要附上可识别身份的医学影像、HCP 受控文件、被试标识、令牌、环境文件，或暴露私有
基础设施的绝对路径。优先提供最小合成复现案例。

本项目是研究软件，不是医疗器械，不提供临床建议。科学分歧或意外仿真结果通常属于
使用问题；只有由安全缺陷引起时，才作为安全漏洞处理。
