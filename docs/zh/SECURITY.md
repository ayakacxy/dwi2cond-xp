请勿附上可识别个人身份的医学影像、HCP 受控文件、被试标识、访问令牌、环境文件，或会暴露私有基础设施的绝对路径。优先使用最小合成示例复现问题。

本项目是研究软件，不是医疗器械，也不提供临床建议。科学方法上的分歧或非预期仿真结果应通过支持渠道讨论；只有源自安全缺陷时才应作为漏洞报告。
