# 社区行为准则

[English](../en/CODE_OF_CONDUCT.md) | [简体中文](../zh/CODE_OF_CONDUCT.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

请尊重他人，保持包容，避免骚扰；围绕问题建设性地讨论，尊重隐私和数据使用限制，
说明科学结论的依据与适用范围，并接受善意的技术审查。

不接受骚扰、歧视、人肉搜索、威胁，以及公开私有或受控访问数据的行为。维护者可
编辑或删除相关内容，并在必要时限制参与。

行为问题请通过 GitHub 私下联系仓库所有者。维护者会公平审阅，尽可能保密，并披露
可能的利益冲突。
