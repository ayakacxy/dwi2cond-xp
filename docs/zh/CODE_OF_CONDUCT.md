# 行为准则

[English](../en/CODE_OF_CONDUCT.md) | [简体中文](../zh/CODE_OF_CONDUCT.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

本项目希望建立相互尊重、包容且无骚扰的社区。参与者应建设性地交流，尊重隐私和数据使用限制，说明科学结论所依据的证据及其适用范围，并接受善意的技术审阅。

骚扰、歧视、公开个人隐私、威胁以及发布私密或受控访问数据均不可接受。维护者可在必要时编辑或移除内容、限制参与，以保护社区成员。

行为问题请通过 GitHub 私下联系仓库所有者。维护者会公平审查报告，尽可能保密，并披露利益冲突。
