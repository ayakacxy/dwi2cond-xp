# 社区行为准则

[English](../en/CODE_OF_CONDUCT.md) | [简体中文](../zh/CODE_OF_CONDUCT.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

参与 issue、讨论和 Pull Request 时，请尊重其他参与者。

- 围绕技术问题讨论，不进行人身攻击。
- 提供建设性反馈，欢迎不同经验水平的贡献者。
- 尊重隐私、署名和数据使用条款。

骚扰、歧视、威胁、曝光他人隐私及反复干扰讨论的行为不可接受。维护者可视情节移除内容、发出警告或限制参与。

行为问题请通过仓库所有者 [GitHub 主页](https://github.com/ayakacxy)提供的联系信息私下反馈，避免在公开 issue 中发布个人信息。维护者会尽可能保密处理。
