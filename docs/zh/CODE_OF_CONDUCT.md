# 行为准则

[English](../en/CODE_OF_CONDUCT.md) | [简体中文](../zh/CODE_OF_CONDUCT.md)

[文档目录](README.md) · [项目首页](../../README.zh-CN.md)

我们希望社区保持尊重、包容，且不受骚扰。请以建设性的方式交流，尊重隐私和数据使用限制，说明科学结论的验证条件，并认真对待善意的技术评审。

骚扰、歧视、人肉搜索、威胁，以及公开私有或受控数据均不可接受。为保护社区，维护者可视情况编辑或删除内容，并限制参与。

行为方面的问题请通过 GitHub 私下联系仓库所有者。维护者将公平审查报告，尽可能保护保密信息，并披露利益冲突。
