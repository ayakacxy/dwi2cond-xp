## 1. 结论

第三次独立复审记录的 `2 P1 + 5 P2` 已逐项整改，并加入能区分修复前后行为的测试。
本轮保留了原有分辨率、迭代次数、停止条件和数值门槛；参考实现失败时也没有静默切换到其他算法。

其中 VN 的旧实现确实出于避免 NaN 的稳定性意图，但
`determinant_scale == 0 -> 1` 会在没有数学定义和 QA 声明的情况下改变结果，不能视为
充分的数值稳定方案。最终行为改为：

- 默认 `error`：非零奇异张量的 VN 行列式归一化明确失败；
- 显式 `regularize`：先按 `max_ratio` 投影奇异特征系统，再执行既有两轮 SimNIBS 安全修正，并记录修复数量；
- 该分支是公开、可审计的稳健扩展，不宣称为 SimNIBS 4.6 对秩亏输入的逐句等价结果。

## 3. 方向算法整改

### 3.1 算法行为

本地实现现在保持以下 NewNifti 语义：

1. 仿射矩阵的三个空间列先转换到 float32；
2. 依次归一化 i/j/k，并以阈值 `1e-4` 按固定顺序做 Gram-Schmidt；
3. 枚举 6 个轴排列与 8 个符号组合；
4. 只接受坐标手性与规范化矩阵一致的候选；
5. 以 float32 矩阵迹最大化选择候选，并用严格 `>` 保留第一个并列结果；
6. 再变换到 FSL `fslreorient2std` 要求的 RAS/LAS 存储坐标手性。

这是一份独立 Python 实现，没有调用 FSL 作为运行依赖。FSL 仍只用于测试期 A/B。

### 3.2 反例验证

审计反例仿射：

```text
[[ 0.601011634,  1.401550531, 0.942415297,  92.374305725],
 [ 0.538023829, -1.309910774, 1.315203071, -25.246667862],
 [-0.660363793,  0.208347276, 1.929259419,  25.766641617],
 [ 0.000000000,  0.000000000, 0.000000000,   1.000000000]]
```

修复后本地与真实 FSL 均选择 `x/y` 翻转、保持形状 `(3,4,5,2)`；数组、qform、sform
以及 voxel-y 对应的单位物理 PE 向量均一致。测试还覆盖 qform-only、sform-active、正负
行列式、全部 48 个带符号排列和 Gram-Schmidt 退化分支。

## 4. 依赖与 FNIRT 边界

发行依赖现在与 `constraints-simnibs46.txt` 和验证环境一致：

```text
numpy==2.3.0

```

这关闭的是“普通安装仍允许已知失败组合”的发布要求，不宣称 FNIRT 的独立优化轨迹在
任意 BLAS、CPU 或未来依赖上逐位相同。冻结栈的既有合成数据端点仍保留非零
场残差；没有放宽 image/field/max 门槛。

## 5. FEM 组合与缓存身份

CHARM/T1 流程现在始终要求 `final_tissues.nii.gz`。FEM 执行额外要求标准
`m2m_<subject>` 目录、网格和 EEG 电极帽。若标准 `<subject>.msh` 不存在但目录中只有一个
网格，静态验证得到的路径会直接赋给 `SESSION.fnamehead`，所以 dry-run、真实
`SESSION._prepare()` 和求解使用同一网格。

FEM 缓存不再以 `simnibs/__init__.py` 代表整个后端。当前运行标识包含：

- SimNIBS 发行版本与 RECORD SHA-256；
- 六个直接计算/组合模块的路径、大小和 SHA-256；
- 求解器名、NumPy/SciPy/PETSc 包版本；
- 当前环境中与求解器对应的本地动态库路径、大小和 SHA-256。

如果 RECORD、关键模块或本地编译求解器标识缺失，真实 FEM 阶段仍可运行，但不会
复用旧求解缓存。这样保留正确性，不用不完整身份做静默复用。

## 6. VN 数值稳定性结论

对非零奇异 diffusion 张量，核心量

```text
g = abs(lambda1 * lambda2 * lambda3) ** (1/3)
```

为零，VN 的 `lambda / g` 没有定义。旧实现把 `g` 改为 1，只能避免除零，不能证明所得
张量是 VN 映射，也没有把修复记录到 QA。

显式 `regularize` 策略先执行各向异性比投影：小特征值至少提高到
`lambda_max / max_ratio`；全非正退化系统使用已声明的组织电导率回退值。
随后重新计算取值为正的行列式缩放系数，再进入原有归一化与两轮 safety correction。
因此它具备三个旧实现没有的性质：

1. 不发生 NaN/Inf；
2. 输出保持正定并受 `max_ratio/max_cond` 约束；
3. 修复策略、数量和参数写入 QA，可由下游拒绝或审计。

默认仍是 `error`，因此普通官方兼容路径不会无提示启用稳健扩展。

## 8. 证据边界

- 本轮没有重新运行完整 HCP 原始 DWI→TOPUP/EDDY→FNIRT→FEM；不能从合成数据和
  `SESSION._prepare()` 推导新的人体端到端数值等价结论。
- 正式流程的 FEM 仍调用真实 SimNIBS 4.6；本地 VN robust 扩展只影响公开
  `tensor-to-mesh` 转换器，不会静默替换正式 SimNIBS 求解的电导率路径。
- 当前结果证明 `053..059` 的确定性反例已关闭，不构成任意输入上的形式化或 bitwise
  等价证明。
