## SimNIBS 4.6 GRE 场图

公开非解剖样例使用 `16x14x12` 幅度图/场图/b0 网格、已解缠的 rad/s 场、`y-` 相位编码、0.5 ms 采样间隔、明确掩膜，不使用中值滤波。Python 使用八个候选计算线程，保留完整 6 自由度互信息 FLIRT 设置，共进行 11,349 次代价计算。

| 实现 | 进程实际耗时 | 流程内部耗时 | 峰值 RSS |
| --- | ---: | ---: | ---: |
| dwi2cond-xp，最终批处理路径 | 1.49/1.51/1.51 s | 0.589/0.632/0.623 s | 204,644–205,204 KiB |
| dwi2cond-xp，保留的批处理前路径 | 6.55/6.81/6.88 s | 5.80–6.08 s | 约 220 MiB |
| SimNIBS 4.6 / FSL 6.0.4 参考流程 | 0.46 s | 已计入 | 未记录 |

最终优化同步推进独立 Brent 搜索轨迹，每轮由 Numba 批量计算候选，仿射矩阵也按批构造。轨迹内候选顺序、代价求和、搜索范围、迭代上限和停止条件均不变。最终矩阵与七份检查的 NIfTI 数组和保留 Python 路径逐位相同，代价计算次数仍为 11,349。矩阵检查/求逆也按批执行，11×11×11 粗网格插值和仿射构造使用向量化。与 FSL 的矩阵最大绝对差仍为 `1.266861e-5`。

`y-` 下，畸变幅度图、映射场、体素位移和校正 b0 相对 L2 误差分别为 `4.56e-8`、`6.66e-7`、`8.93e-7`、`7.36e-8`，映射和校正掩膜完全相同。`y` 下对应为 `4.98e-8`、`2.03e-7`、`3.06e-7`、`6.64e-8`，掩膜同样完全相同。FSL 的优化器和启动过程使用编译后的 C++，在这个极小输入上更快；这里没有 Python 更快的结论，也不能据此预测真实解剖 GRE 图像的性能。

全部导入和 Numba 内核已加载后，同进程四次流程内部耗时为 `0.585/0.358/0.413/0.400 s`。这组记录用于区分计算和启动开销，不与新进程 FSL 参考流程计算加速比。

## 自动仿射 DTI→T1 配准

私有全头比较使用同一拟合张量/FA/SSE 和 CHARM T1、标签图、偏置校正 T1。Python 执行完整 12 自由度配准、独立 6 自由度 QA 配准、仿射张量插值与旋转、FA/V1 分解、掩膜、全部 gzip 输出及 FA/SSE QA。请求八个候选计算线程，底层运行库没有额外限制线程数。

| 实现 | 实际耗时 | CPU 利用率 | 峰值 RSS |
| --- | ---: | ---: | ---: |
| dwi2cond-xp 最终进程 | 53.23 s | 2351% | 3,103,744 KiB |
| dwi2cond-xp 优化前进程 | 100.90 s | 1607% | 3,410,112 KiB |
| SimNIBS 4.6 / FSL 6.0.4 | 233.18 s | 99% | 2,142,568 KiB |

同机最终耗时相对 FSL 为 `4.38x`，相对保留的 Python 基线为 `1.90x`。性能分析中，T1 准备约 5 秒，重叠执行的 12/6 自由度 FLIRT 为 17–20 秒，张量与派生输出关键路径约 29 秒。保留的优化让独立配准、张量分量和源掩膜采样，以及张量 gzip 和只读 FA/V1 分解重叠执行。尝试过后台 T1 gzip，但内存带宽竞争拖慢了 FLIRT，因此未保留。

与 FSL 相比，12 自由度矩阵最大绝对差为 `0.00661515`，移动图像视野角点位移差的均值/最大值为 `0.00385192/0.00771821 mm`。配准张量和 FA 相对 L2 为 `2.37187e-4`、`3.23951e-4`，两者 FA 支持域均恰为 3,947,315 个体素。V1 轴向角误差均值/P99 为 `0.0156600/0.155766` 度；极少数低各向异性或边界位置的最大值为 `84.2445` 度。6 自由度 FA 与 SSE QA 相对 L2 为 `1.23549e-4`、`2.22144e-4`。输出网格、T1 脑区和脑边缘完全一致。

优化后的矩阵、配准张量、有效性掩膜与 QA 数组和优化前 Python 路径逐位相同。恢复 FSL 的张量分解规则后，三个体素的 FA/V1 按预期发生变化：最大特征值不为正时，这些输出须保持为零。

## SimNIBS 4.6 固定 TOPUP 功能

公开非解剖反向相位编码样例是 `16x14x12` 网格上的两个体积。两实现都使用未改动的九级 `b02b0_nosubsamp.cnf` 设置；Python 使用八个 Numba 工作线程。

| 实现 | 实际耗时及计时范围 | 峰值 RSS 中位数 |
| --- | ---: | ---: |
| dwi2cond-xp 完整 `prepare-topup` 命令 | 2.14/2.06/2.12/2.18/2.34/2.04/2.03/2.04/2.26 s | 约 225 MiB |
| dwi2cond-xp 同进程、内核已加载的算法 | 0.681/0.630/0.609/0.648/0.709/0.610/0.592 s | 已计入上行 |
| FSL 6.0.4 `topup` | 4.77/4.59/4.61 s | 约 14 MiB |

独立进程测量前已生成 Numba 磁盘缓存。完整命令中位数为 2.12 和 4.61 秒，在这个小样例上为 `2.17x`。此前 Python 优化阶段的中位数为 4.14、3.31 和 2.91 秒。优化包括延迟导入 CLI 分支和预处理接口、缓存重复刚体逆向矩阵及其逆矩阵、跳过支持域确定不重叠的系数对和体素、稠密存储小型 LM 系统但保留按列递增的 PCG 累加，以及复用相同正则化乘积。层级设置、迭代次数、停止条件和非零项 z/y/x 累加顺序不变，五份数值文件与前一 Python 输出逐位相同。早期一组同进程已加载内核的中位数约 1.12 秒，未与新启动 FSL 进程比较。首次 JIT 编译是另行记录的一次性开销。

第五轮优化将独立且可能非零的场 Hessian 元素分配到八个线程，每个元素保留 FSL 的 z/y/x 累加顺序，并缓存有序系数对任务及重复的一维弯曲核重叠。五份公开文件与源码修正后的基线逐位相同。修改后一次仍需补编译缺失签名的运行耗时 5.30 秒；完全空缓存此前约需 15 秒，两者都不混入稳定状态比较。

第六轮按实际重叠支持域排序独立 Hessian 元素，再均分线程任务；每个元素的 FSL z/y/x 求和不变。九种系数网格上原有 17–47% 的静态任务不均衡因此消除。同时在一次体素遍历中计算两个独立样条转置累加器，各自顺序不变。五份文件与第五轮逐位相同，单线程与八线程输出也逐位相同。进程内预热一次后，六次算法中位数为 0.823 秒，只描述长流程中内核已加载的阶段，不与新 FSL 进程比较。合并稠密场和导数展开的候选虽逐位一致，但更慢，未保留。

第七轮将两个独立周期三次扫描采样器合为一次 Numba 调用，为重复有序正则化乘积保留 CSR 视图，并并行展开独立场体素，每体素系数 z/y/x 累加顺序不变。原始 CSC Hessian 和按系数展开方法保留为数值参考。五份文件与第六轮逐位相同，最终单线程与八线程文件也逐位相同。七次完整命令中位数为 2.17 秒；预热一次后七次算法中位数为 0.630 秒，比第六轮进程内算法减少约 23.5%。预计算稠密三维基底 Hessian 的候选虽然逐位一致，却将峰值 RSS 增至约 312 MiB，且没有缩短耗时，因此未保留。

第八轮将完整稠密 PCG 迭代编译为一次 Numba 调用，保留显式 Python 参考后端和同样的按列递增矩阵向量累加。五个独立运动交互转置列也在一次系数/体素遍历中计算，每列 z/y/x 求和顺序不变。主表九次新进程命令中位数为 2.12 秒，内部算法中位数为 1.497 秒。五份数值文件与第七轮逐位相同。批量重网格、轴旋转缓存、跨级目标复用、按相位特化的 Hessian 和成对直接/导数运动计算均未改善完整耗时，没有保留。

另一次针对启动开销的第四轮优化，将包根张量 API 和关闭进度条时的路径改为延迟加载。在后来同机较高负载下，修改前命令耗时 `3.73/3.61/3.84 s`（中位数 `3.73 s`），最终路径为 `3.47/3.49/3.52 s`（中位数 `3.49 s`）；同时 FSL TOPUP 为 `4.90/4.72/4.72 s`（中位数 `4.72 s`），对应 `1.35x`。五份输出仍逐位相同。这是当时负载下的配对优化样本，不替代主表较安静环境的数据。同进程、内核已加载时，稀疏参考路径十次中位数为 `0.751 s`。

另有两个候选未采用：将场 Hessian 的一个三角部分镜像到另一半会改变真实末位差异（最大不对称量 `6.82e-13`）；把缓存稀疏正则化乘积替换为有序稠密内核虽逐位一致，但交替同进程比较更慢（中位数 `0.806 s` 对 `0.751 s`）。

恢复 FSL 6.0.4 运动矩阵中 float 三角运算后，最终场相对 L2 和最大绝对差为 `0.00429657`、`0.451101 Hz`。联合有效掩膜内校正图像对相对 L2 和最大绝对差为 `0.00161346`、`1.41406`；图像对一致性为 `0.00922993`，FSL 为 `0.00892792`。运动参数最大绝对差为 `0.00241634`。运动矩阵本身与直接 FSL C++ 探针相差不超过 `2.78e-17`，剩余输出差异由优化轨迹放大。这些结果不代表逐位一致；在实际解剖图像尺寸上完成同形状基准前，也不能推广其性能。

发布 wheel 还在不下载依赖的条件下安装到独立 overlay，读取未改动的 SimNIBS 4.6.0 环境。`pip check` 未发现依赖问题。同一样例首次进程包括 Numba 编译，耗时 `37.78 s`；后续独立进程复用内核缓存，耗时 `9.34 s`。两次均检出相同四个异常切片，参数和异常图逐字节相同。缓存 wheel 测试用于确认打包兼容性，主性能结论仍以表中的源码/FSL 严格比较为准。

## SimNIBS 4.6 legacy 校正

公开非解剖样例在 `20x20x20` 网格上包含 14 个体积。Python 命令使用八个工作进程，FSL 参考使用未修改的 SimNIBS 4.6 legacy 流程。

| 实现 | 实际耗时 | 峰值 RSS |
| --- | ---: | ---: |
| dwi2cond-xp 进程，3 次中位数 | 2.75 s | 226,824 KiB |
| dwi2cond-xp 流程内部，3 次中位数 | 1.951 s | 已计入上行 |
| SimNIBS 4.6 / FSL 6.0.4 参考流程 | 6.766 s | 145,436,672 bytes |

Python 进程耗时为 `2.75/2.71/2.87 s`，中位数相对 FSL 为 `2.46x`。Linux 仅在独立的 4 mm 逐体积阶段使用八进程；源码要求的首轮 8 mm 传播仍串行执行。Windows 和 macOS 使用线程后端保持相同算法。尚无 HCP legacy 校正性能测量，P4 `nomoco` 结果不能推广到该模式。

normcorr 热点合并坐标生成、边缘加权和线性采样，不启用 fast-math；显式保留全部 FSL float32 乘积舍入位置，并复现 NumPy/FSL 先 x、再 y、再 z 的成对求和。三次独立运行中，14 个矩阵及校正 DWI、均值、掩膜、张量、FA、SSE、有效性掩膜均与优化前 Python 输出逐位相同。

14 个最终变换中，矩阵最大绝对差为 `0.0699333`；移动视野角点位移差均值/最大值为 `0.0652414 mm`、`0.0941606 mm`。校正 DWI 和校正 `b>0` 均值相对 L2 为 `0.00910157`、`0.0130192`，掩膜 Dice 为 `0.993194707`。固定使用 FSL 矩阵时，Python sinc 重采样相对 L2 为 `7.42962e-7`，最大绝对差为 `0.00428009`，说明主要差异来自优化终点，而非坐标转换或最终插值。

优化后的宽度七 Hanning-sinc 内核与保留向量化参考逐位一致，在该样例上将最终重采样从约 8.39 秒降至 0.054 秒。每个最终体积仍仅插值一次。

合成输入边缘锐利且无噪声，边界变换的小幅差异使张量和 SSE 相对误差不稳定。共同掩膜内张量/FA/SSE 相对 L2 为 `0.772510`、`0.0373037`、`1.06086`；掩膜腐蚀三次后，剩余 836 个内部体素上张量和 FA 为 `0.00287432`、`0.00248977`。两组结果均保留，不宣称全掩膜张量等价。

## SimNIBS 4.6 `nomoco` 原始 DWI 流程

私有 HCP b0+b1000 输入在 `145x174x145` 网格上有 108 个体积。两次运行使用相同、已统一 b0 值的 b 值及 b 向量。Python 使用八工作进程，每进程一个 BLAS 线程；FSL 使用未修改的 SimNIBS 4.6 `--prepro --nomoco --keepstuff` 流程。

| 实现与输入 | 并行方式 | 实际耗时 | CPU 利用率 | 峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| dwi2cond-xp，检查通过的 `.nii` mmap | 8 个工作进程 | 18.82 s | 306% | 1,770,256 KiB |
