## 2026-10-14：v0.4.0 完整流程对照

v0.4.0 包含[发布说明](RELEASE_NOTES_v0.4.0.md)中的算法修复与性能优化。
本次实测科学源码保留在 v0.4.0 中，其后更新了发布元数据和测试；各次运行在同一
Linux 服务器上使用同一私有 HCP 输入。

DWI 为 `145×174×145×108`、1.25 mm、float32，包含 18 个精确 b=0 和 90 个 b≈1000
体积，使用相同梯度与梯度非线性数据；CHARM T1/分割 seed 相同，为 `260×311×260`、
0.7 mm。各条路径均执行 nomoco、非线性配准、原生 QA 和 m2m 张量发布，FEM 关闭；
Python 路径还执行项目全部汇总 QA。主机为 Xeon Gold 6230 和 RTX 2080 Ti，固定
八个物理核心，Numba/workers 最多为 8，BLAS/OMP/MKL 为 1。

每条 Python 路径取一个独立进程、全新输出目录的正常热缓存样本，均无 JIT 缓存写入；
所有计算阶段完成且无产物缓存命中。FSL 完整执行一次原生流程，不涉及 JIT。没有清除
操作系统文件缓存；首次编译和探针样本不计入表格。计时包含启动、导入、计算、读写、
QA 和发布；seed 复制与后续数值核验在计时外。CPU 整链在禁止可选 GPU 模块导入的
条件下成功完成；GPU 路径使用 FP64 Hessian 组装和 PPD 后端。PPD 采样保留 float32
检查点，Jacobian 和矩阵运算为 float64。

| 实现 | 完整耗时 | 峰值主机进程树 RSS | 峰值 GPU 分配 |
| --- | ---: | ---: | ---: |
| v0.4.0，CPU | 205.451992 s | 6.497955 GiB | 不使用 |
| v0.4.0，GPU | 163.341718 s | 6.723415 GiB | 8.833985 GiB |
| 公开 `v0.3.0`，CPU | 564.406214 s | 25.468868 GiB | 不使用 |
| 原生 SimNIBS 4.6 / FSL 6.0.4 子脚本 | 1290.072619 s | 3.794250 GiB | 不使用 |

相对公开 `v0.3.0`，当前 CPU/GPU 的观察耗时比分别为 **2.747× / 3.455×**，
时间减少 **63.599% / 71.060%**，主机峰值 RSS 减少 **74.487% / 73.601%**。
相对 FSL，耗时比分别为 **6.279× / 7.898×**；当前 CPU 与 GPU 的耗时比为 **1.258×**。
FSL 使用的主机内存更少，当前 CPU/GPU 的 RSS 峰值约高 **71% / 77%**。RSS 每 0.2 秒
采样本次进程树，共享页可能重复计入。GPU 分配每 0.5 秒采样，包含上下文和分配器
缓存，与主机 RSS 分开列出；这些峰值不是最低内存需求。

公开基线使用留档的 v0.3.0 wheel，SHA-256 为
`bbcc959280de4b1405a4d17697ef9f097b89f67222b8804c36cee0b9198e9493`；41 个包内 Python
文件与 wheel 和本地 tag 提交 `b71d320a5095efb95f3547ac8648f5fa5de7bd19` 一致。
共享输入哈希相同。v0.4.0使用 corrected/physical/stable 几何，公开版与 FSL
保留此前的坐标/PPD 行为；算法修复属于跨版本变化，耗时比不证明纯硬件加速或各流程
数值等价。

FSL 对照调用原始官方预处理/配准子脚本，两次 WLS 均传入原生 `--gradnonlin`，
保留中间文件、原生 FA/V1、正式及原始拟合的 FA/SSE QA 和张量发布，跳过 `nii2msh`
可视化导出。它没有增加项目汇总 QA、有效性/PPD 诊断、发布事务 manifest 或额外稠密
FNIRT 场/Jacobian 输出；在相同八核预算内，原生 FSL 经常只使用一个核心。比较耗时比
时需要结合这些输出与调度差异。

在原空间，v0.4.0 与 v0.3.0 掩膜 Dice 为 1，共同掩膜的 FA/SSE 完全相同，张量相对 L2 为
`6.46e-17`。v0.4.0 与 FSL 掩膜 Dice 为 `0.9961145`，共同掩膜的张量/FA/SSE 相对 L2 为
`6.2193e-7 / 5.2792e-7 / 5.0044e-6`，以参考侧为分母。当前 CPU/GPU 的 64 份数值
产物中 61 份逐字节相同，稠密位移场、系数、掩膜和 LM 记录一致。脑内张量相对 L2 为
`1.8693e-9`，健康谱 V1 轴向夹角 P99 为 `1.2074e-6` 度；健康谱要求双方 FA>0.1，
`(λmax−λsecond)/max(abs(λ))>1e-5`，夹角忽略向量符号。最终输出网格一致，已检查的
产物数值有限。WLS 没有半正定约束，仍可能出现负特征值和 FA>1；不能据此宣称全部
张量半正定或最终结果与 FSL 等价。

## 原始 DWI 预处理

### HCP b0+b1000 的 `nomoco` 流程

私有输入为 `145x174x145` 网格上的 108 个体积，两种实现使用相同的 b0 归一化 b 值
和 b 向量。Python CLI 用 8 个 worker 进程，每进程 1 个 BLAS 线程；参考使用未修改的
SimNIBS 4.6 `--prepro --nomoco --keepstuff` 流程。

| 实现与输入 | 执行方式 | 实际耗时 | CPU 利用率 | 峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| dwi2cond-xp，验证后直接 mmap 的 `.nii` | 8 workers | 18.82 s | 306% | 1,770,256 KiB |
| dwi2cond-xp，只解码一次的 `.nii.gz` | 8 workers | 52.92 s | 170% | 4,791,436 KiB |
| SimNIBS 4.6 / FSL 6.0.4 | 1 个进程 | 257.30 s | 99% | 3,167,907,840 bytes |

未压缩与 gzip 输入的实际耗时比分别为 `13.67x` 和 `4.86x`。直接读取的输入必须是
标准方向、值有限且非负的 float32 NIfTI，使用 mmap 前按 z 块检查。gzip 输入只解码
一次，生成各 worker 共享的未压缩拟合图像。两种 Python 方式的 b0、掩膜、脑图、张量、
FA、SSE 和有效性数组逐位相同。因此，输入编码及保留中间文件的差别属于计时条件。

这次历史测量没有固定 FSL 参考输入的文件编码，因此 `13.67x`/`4.86x` 只保留为
开发规划时的观察，不作为相同输入编码下的受控加速比较。

与 FSL 相比，脑掩膜 Dice 为 `0.993205660`。共同掩膜的 877,892 个体素中，张量、FA、
SSE 相对 L2 分别为 `6.4647e-6`、`6.9847e-6`、`3.5067e-5`。拟合比较应使用共同
掩膜；全网格误差主要受 BET 边界不同造成的零填充影响。

### Legacy 校正

公开的非解剖合成输入为 `20x20x20` 网格上的 14 个体积。Python CLI 用 8 个 worker，
参考使用未修改的 SimNIBS 4.6 legacy 流程。

| 实现 | 实际耗时 | 峰值 RSS |
| --- | ---: | ---: |
| dwi2cond-xp 进程，3 次中位数 | 2.75 s | 226,824 KiB |
| SimNIBS 4.6 / FSL 6.0.4 测量程序 | 6.766 s | 145,436,672 bytes |

Python 三次进程耗时为 `2.75/2.71/2.87 s`，中位数比为 `2.46x`。Linux 只在独立的
4 mm 逐体积阶段使用 8 进程，上游规定的首轮 8 mm 传播保持串行。被测优化快照保留
最终插值次数；与保留的 Python 基线相比，矩阵、校正 DWI、均值图、掩膜、张量、FA、
SSE 和有效性掩膜逐位相同。

14 个变换中，与 FSL 的最大矩阵绝对差为 `0.0699333`；移动图像视野角点位移差的
均值和最大值为 `0.0652414 mm`、`0.0941606 mm`。校正 DWI 和 `b>0` 均值图的相对
L2 为 `0.00910157`、`0.0130192`，掩膜 Dice 为 `0.993194707`。固定使用 FSL 矩阵
后，Python sinc 重采样相对 L2 为 `7.42962e-7`、最大绝对误差 `0.00428009`，说明
主要差异来自优化器终点。

该合成输入边界锐利且无噪声，张量和 SSE 比值对微小边界变换敏感。共同掩膜内张量/FA/
SSE 相对 L2 为 `0.772510/0.0373037/1.06086`；掩膜腐蚀三次后剩余 836 个内部体素，
张量和 FA 相对 L2 降为 `0.00287432/0.00248977`。

### GRE 场图校正

公开非解剖合成输入的幅度图/场图/b0 网格为 `16x14x12`，使用已解缠的 rad/s 场、
`y-` 相位编码、0.5 ms dwell time、明确掩膜、不作中值滤波，候选实现使用 8 个 worker。
完整 6 自由度互信息 FLIRT 配准共执行 11,349 次代价计算。

| 实现 | 进程实际耗时 | 记录的流程耗时 | 峰值 RSS |
| --- | ---: | ---: | ---: |
| dwi2cond-xp 被测快照 | 1.49/1.51/1.51 s | 0.589/0.632/0.623 s | 204,644–205,204 KiB |
| SimNIBS 4.6 / FSL 6.0.4 测量程序 | 0.46 s | 包含在总耗时中 | 未记录 |

优化保留候选顺序、代价归约、搜索范围、迭代上限与停止条件。最终矩阵和检查的七个
NIfTI 数组与 Python 基线逐位相同，代价计算次数不变。与 FSL 的矩阵最大绝对差为
`1.266861e-5`。

`y-` 时，畸变幅度图、映射场、体素位移和校正 b0 的相对 L2 分别为 `4.56e-8`、
`6.66e-7`、`8.93e-7`、`7.36e-8`；映射和校正掩膜完全相同。`y` 时对应值为
`4.98e-8`、`2.03e-7`、`3.06e-7`、`6.64e-8`，掩膜同样完全相同。这个很小的合成
输入上 FSL 更快，编译实现的优化器与启动开销占主要影响；不能据此推断解剖影像的 GRE
耗时。

### 固定 TOPUP 子集

公开反向相位编码输入是 `16x14x12` 网格上的两个体积。两种实现均使用未修改的
`b02b0_nosubsamp.cnf` 九级配置。Python 用 8 个 Numba worker，独立进程测量前已建立
Numba 磁盘缓存。

| 实现 | 完整进程实际耗时 | 峰值 RSS 中位数 |
| --- | ---: | ---: |
| dwi2cond-xp `prepare-topup` CLI | 2.14/2.06/2.12/2.18/2.34/2.04/2.03/2.04/2.26 s | 约 225 MiB |
| FSL 6.0.4 `topup` | 4.77/4.59/4.61 s | 约 14 MiB |

中位数分别为 `2.12 s` 和 `4.61 s`，实际耗时比为 `2.17x`。被测 Python 快照保留
九级配置、迭代次数、停止条件和非零项的有序累加；五项公开输出与源码修正后的 Python
基线文件逐位相同。首次 JIT 编译不计入这组缓存已建立的测量。

与 FSL 相比，最终场相对 L2 为 `0.00429657`，最大绝对差为 `0.451101 Hz`。联合
有效掩膜内，校正图像对相对 L2 为 `0.00161346`，最大绝对差 `1.41406`；图像对一致性
为 `0.00922993`，FSL 为 `0.00892792`。运动参数最大绝对差 `0.00241634`；运动矩阵
与直接 FSL C++ 探针的误差在 `2.78e-17` 内。剩余差异反映优化轨迹对数值差别的放大。
输入很小，不能代表解剖尺寸 TOPUP 的性能。

### EDDY `--repol`

公开确定性输入为 `26x26x18` 网格上的 26 个体积：两个 b0、一个 24 方向壳层、已知
体积运动与二次涡流，以及四个注入的异常切片。两种实现在同一主机使用种子 1 和 8 线程。
完整计时包含进程启动、NIfTI 读写、五轮配准、预测替换、b 向量旋转、壳层对齐和结构化输出。

| 实现 | 实际耗时 | 用户 CPU 时间 | 峰值 RSS |
| --- | ---: | ---: | ---: |
| dwi2cond-xp `prepare-eddy` | 7.76 s | 39.68 s | 238,076 KiB |
| FSL 6.0.4 `eddy_openmp` | 9.77 s | 37.93 s | 36,680 KiB |

完整进程耗时比为 `1.26x`，Python 记录的算法耗时为 `6.896 s`。四个异常体积/切片
位置 `(5,8)`、`(11,9)`、`(18,7)`、`(23,10)` 全部准确识别。重复 Python 运行的参数
和异常图文件逐字节相同。

3,512 个脑掩膜体素内，校正 DWI 相对 L2 为 `0.0035352`；去异常后的扫描空间数据和
旋转 b 向量相对 L2 为 `0.0031508`、`0.0014983`。用相同项目 WLS 实现分别拟合两份
校正结果，张量/FA/SSE 相对 L2 为 `0.0060714/0.0035526/0.0539494`；SSE 绝对差的
均值/P99/最大值为 `0.001279/0.01844/0.07959`。接近零的残差分母会放大 SSE 相对值，
因此同时报告绝对统计。

## DTI→T1 配准

### 自动仿射配准

私有全头比较使用相同的拟合张量/FA/SSE 和 CHARM T1、标签图、偏置校正 T1。Python
计时包含完整 12 自由度配准、独立 6 自由度 QA 配准、仿射张量插值与旋转、FA/V1 分解、
掩膜、gzip 输出和 FA/SSE QA。请求 8 个候选 worker，底层运行库未额外限制线程。

| 实现 | 实际耗时 | CPU 利用率 | 峰值 RSS |
| --- | ---: | ---: | ---: |
| dwi2cond-xp 被测快照 | 53.23 s | 2351% | 3,103,744 KiB |
| SimNIBS 4.6 / FSL 6.0.4 | 233.18 s | 99% | 2,142,568 KiB |

同机实际耗时比为 `4.38x`。性能分析显示 T1 准备约 5 秒，重叠执行的 12/6 自由度
配准约 17–20 秒，张量及衍生输出的关键路径约 29 秒。

与 FSL 相比，12 自由度矩阵最大绝对差为 `0.00661515`；移动视野角点位移差的均值/
最大值为 `0.00385192/0.00771821 mm`。配准张量和 FA 相对 L2 为 `2.37187e-4`、
`3.23951e-4`；两者 FA 有效区域均为 3,947,315 个体素。V1 轴向夹角均值/P99 为
`0.0156600/0.155766` 度；最大值 `84.2445` 度出现在低各向异性或边界体素。独立
6 自由度 FA 和 SSE QA 相对 L2 为 `1.23549e-4`、`2.22144e-4`；输出网格、T1 脑图和
脑边缘完全相同。

优化快照的矩阵、配准张量、有效性掩膜和 QA 数组与 Python 基线逐位相同。恢复“最大
特征值为正才输出张量分解结果”的上游规则后，FA/V1 在三个体素上发生变化。

### 非线性配准

公开 `24x23x22` 合成输入在两种实现中使用相同 FA、张量、T1 参考与仿射初值。FSL
执行固定的 `fnirt --subsamp=8,4,2,2`、`vecreg` 和张量分解；Python 另输出有效性
掩膜、两种 Jacobian 结果和结构化 QA。

| 实现 | 实际耗时 | 峰值 RSS |
| --- | ---: | ---: |
| dwi2cond-xp 完整 CLI，8 workers | 9.74 s | 289,984 KiB |
| SimNIBS 4.6 / FSL 6.0.4 测量程序 | 9.203 s | 118,861,824 bytes |

在这个较小输入的完整计时范围内，Python 约慢 5.8%，同时生成上述额外输出；内部记录
耗时为 `8.98 s`。

被测快照的形变后 FA 相对 L2 为 `0.00309871`；形变向量误差均值/P99/最大值为
