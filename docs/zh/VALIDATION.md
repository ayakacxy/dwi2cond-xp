本页汇总 `v0.1.0` 发布时记录的验证结果。该标签于 2026-08-29 因文档和发布元数据修正而重新发布，算法源码仍为原始 `v0.1.0`。此次文档更新没有重跑 HCP、FSL、FEM 或性能实验。

## 可用的验证材料

1. 本标签的自动化测试可从源码重新运行。配置本机可选 FSL 参考测试后，发布记录为 `144 passed`，覆盖全部 `1,644/1,644` 条可执行包语句（`100.00%`）。
2. 下文的 HCP、合成球形网格和真实 FEM 结果来自历史实验记录。其受控或私有输入及被试级机器可读输出不随仓库分发，因此仅靠仓库无法原样重现这些实验。

这些结果适用于所述输入和处理阶段，不能据此判断原始 DWI 校正、自动配准、其他采集方案、其他求解器或后续版本的表现。

## 自动化测试

合成数据测试覆盖梯度约定、WLS 拟合、无效体素处理、仿射张量映射与重定向、电导率模式、SimNIBS 对象构建、WM/GM/CSF 输出掩膜、先导场各轴排列、绘图和输出清单。FSL 对照为可选参考测试；找不到 `dtifit` 时会明确标记为跳过。

本版本的 Linux、macOS 和 Windows 工作流使用相同的包语句覆盖率要求（100%）。跨平台 CI 通过不代表各平台都完成了 FSL 对照。

## DTI 数值对照

合成 DTI 数据与 FSL 6.0.4 的 `dtifit --wls --gradnonlin` 对比，张量最大、平均绝对差分别为 `1.16e-10` 和 `8.26e-12`。

私有 HCP 对照使用 b=0 与 b=1000 壳层、相同的 WLS 拟合及梯度非线性设置，共比较 5,287,164 个有效张量分量。最大、平均、p99 绝对差分别为 `2.43e-6`、`4.78e-10`、`2.10e-9`，相对 L2 误差为 `4.18e-6`。最大误差主要来自少量边界体素；这说明整体结果接近，并不表示逐元素完全相同。

HCP 拟合脑掩膜包含 881,299 个体素，其中 881,194 个有效，105 个无效体素被填零并记录在有效掩膜和 QA 报告中。

## 电导率对照

历史合成球形网格实验与 SimNIBS 4.6 比较了 274,770 个电导率分量。`vn` 的最大绝对差为 `0`，`dir` 和 `mc` 均为 `2.22e-16`。这些结果对应实验所用张量、组织标签、标量参考值、权重及模式参数，不能证明任意退化张量或自定义参数组合都完全等价。

## 固定电极配置的 FEM

一名私有 HCP 被试具有完整的 T1/T2 CHARM 头模型和 T1 网格张量。`scalar`、`vn`、`dir`、`mc` 四种模式均完成了 Pardiso 求解的 C3→C4、1 mA 仿真。记录的向量电场 NIfTI 数值均有限；施加输出掩膜后，保留白质、灰质和脑脊液，标签 1、2、3 以外的体素均为零。

在同一原始映射下，标量模式的 Pardiso/Hypre 对照得到最大绝对差 `2.98e-8 V/m`、相对 L2 误差 `6.28e-9`。这只是单一输入的标量求解器比较，不能据此认为四种模式下两种求解器均等价。

本版本也提供全电极先导场配置，以及 HDF5/NPY/JSON 文件的检查和导出，并进行了单元测试。`v0.1.0` 的验证记录不包含真实被试的完整全电极先导场计算。

## 功能限制

`v0.1.0` 从外部预处理后的 DWI 或外部生成的张量开始，不负责原始 DWI 的运动、涡流、磁敏感性/EPI 畸变校正，也不估计 DTI→T1 仿射或非线性配准。张量映射仅使用用户提供的仿射矩阵和有限应变重定向；不含非线性 PPD 重定向。

仓库及 Release 不包含 HCP 原始数据、解剖影像、体数据派生物、被试标识或被试级机器可读产物。
