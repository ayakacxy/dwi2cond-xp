## CPU 与 CUDA 对照

完整 Linux/RTX 2080 Ti 运行使用一组 HCP 单壳层输入，包含 `nomoco`、梯度偏差校正、非线性配准、QA 和 m2m 发布，关闭 FEM。CPU 运行在禁止可选 GPU 模块导入时完成。

64 项数值产物中有 61 项在 CPU 与 CUDA 间逐字节一致，掩膜、FNIRT 系数、稠密场和 LM 记录一致。脑内张量相对 L2 为 `1.8693e-9`，最终 FA 最大绝对差为 `8.7172e-7`。

忽略特征向量正负号后，健康 V1 轴向角 P99 为 `1.2074e-6` 度。该指标要求两份输出 FA>0.1，且相对主特征值间隙>1e-5，覆盖全部健康体素。细节与计时范围见[性能报告](BENCHMARKS.md)。

## 数值参考示例

固定预处理和配准路径具有真实 FSL 6.0.4 的合成对照，下表保留各自测试输入上的结果：

| 示例 | 记录结果 |
| --- | --- |
| 存储方向 | 高斜置反例和全部 48 种带符号置换匹配 FSL 离散方向选择 |
| 含梯度非线性的 WLS | 合成张量最大/平均绝对差 `1.16e-10 / 8.26e-12` |
| GRE 变换组合 | 非恒等 90° premat 加一体素位移，在 `9×9×3` 三线性输入上数组精确一致 |
| TOPUP | 场和校正图像对相对 L2 为 `0.00430 / 0.00161` |
| EDDY | 检出全部 4 个注入坏切片，无额外异常；内部 DWI/张量相对 L2 为 `0.0035352 / 0.0060714` |
| FNIRT | 校正图像/场相对 L2 为 `0.001298916 / 0.175488519`，最大场分量差 `0.994548967 mm` |

FNIRT 与独立的 FSL 优化器仍有非零场差异。坐标回归还覆盖存储置换、两种手性、非 1 mm PPD、头字段/仿射采样不一致、电导率消费端及发布失败。无半正定约束的 WLS 允许负特征值和 FA>1。

## FEM 与先导场检查

早期私有被试研究完成了 CHARM，以及 `scalar`、`vn`、`dir`、`mc` 的真实 C3 到 C4、1 mA Pardiso 求解。向量场有限且掩膜限定于 WM/GM/CSF。共同映射上的标量 Pardiso/Hypre 最大绝对差为 `2.98e-8 V/m`，相对 L2 为 `6.28e-9`。

后续 FEM 组合修复通过真实 SimNIBS 4.6 `SESSION._prepare()`，以及构造、适配器和发布测试检查；这些变化后未重复完整被试求解。先导场检查覆盖配置、参考电极和 HDF5/NumPy 约定，不包含完整全电极被试性能测试。

## 历史记录

v0.3.0 科学源码基线 `ae5a6a7` 完成 666 项主测试、12 项电极配置测试及合成 TOPUP/EDDY/FNIRT CLI 流程，覆盖 13,663/13,663 条语句。这些计数属于该源码快照。

早期 HCP WLS 验证包含 881,299 个掩膜体素，其中 881,194 个有效、105 个无效并填零。5,287,164 个有效值的张量相对 L2 为 `4.18e-6`，最大/平均/P99 绝对差为 `2.43e-6 / 4.78e-10 / 2.10e-9`。

2026-08-23 非线性研究记录的位移向量平均/P99/最大误差为 `0.0130 / 0.0626 / 0.1828 mm`，张量相对 L2 为 `0.00631`，支持集 Dice 为 `0.99962`，V1 平均/P99 角差为 `0.343 / 3.104°`。使用相同 FSL 形变后，PPD 张量相对 L2 降到 `1.51e-6`，将主要差异定位到独立优化的形变。
