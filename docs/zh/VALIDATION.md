## 公开合成数据比较

本版本使用的十份 FSL 参考 JSON 定义与汇总见 [FSL 参考实现](FSL_REFERENCE.md)。合成 DTI 样例与 FSL 6.0.4 `dtifit --wls --gradnonlin` 比较，张量最大和平均绝对差为 `1.16e-10` 和 `8.26e-12`。

固定预处理样例中，TOPUP 场和校正图像对的相对 L2 误差为 `0.00430` 和 `0.00161`。EDDY 检出全部四个注入的异常切片，无额外误报；掩膜内部的校正 DWI 和下游张量相对 L2 误差为 `0.0035352` 和 `0.0060714`。这些数值只支持所测 SimNIBS 4.6 功能及固定输入，不能代表任意 TOPUP 或 EDDY 配置。

公开非线性样例的配准 FA 相对 L2 为 `0.00309871`，形变向量误差的均值/P99/最大值为 `0.204/0.603/1.147 mm`，Jacobian 相对 L2 为 `0.0253746`，共同张量支持域上的相对 L2 为 `0.0445701`。这些是最终输出指标，不表示系数或优化轨迹与 FSL 逐位相同。

## 沿用的真实数据与电导率结果

一个私有 HCP b0+b1000 输入中，对 5,287,164 个有效数值的张量比较得到最大、平均和 P99 绝对差 `2.43e-6`、`4.78e-10`、`2.10e-9`，相对 L2 为 `4.18e-6`。极少数边界体素主导了最大误差。该结果对应所记录的 WLS 阶段，并非 2026-08-29 重跑的原始 DWI 完整流程。

合成球面网格上的 274,770 个电导率分量与 SimNIBS 4.6 比较，`vn` 的最大绝对差为 `0`，`dir` 和 `mc` 为 `2.22e-16`。保留材料是汇总文档，不含机器可读比较记录，因此这里仅沿用对应阶段的结果。

同一历史被试完成了 T1/T2 CHARM 头模型，以及 `scalar`、`vn`、`dir`、`mc` 四种模式的 C3→C4、1 mA Pardiso FEM。最终向量电场 NIfTI 全部数值有限；白质、灰质和脑脊液内有有效值，按所述掩膜处理后其他体素为零。在共同映射上，标量 Pardiso/Hypre 最大绝对差为 `2.98e-8 V/m`，相对 L2 为 `6.28e-9`。这证明历史四模式运行已完成，不代表当前 tag 从原始 DWI 到 FEM 的完整重跑。

## 局限与后续版本

HCP 原始数据和被试派生体数据均未公开。真实数据结果主要来自一个私有被试，完整被试的全电极先导场运行不在已完成的验证范围内。阶段结果不能推广为任意完整流程的一致性或加速结论。

项目仅实现 SimNIBS 4.6 `dwi2cond` 所需的固定 FSL 功能，不是通用 FSL 替代品。后续审计发现的 v0.2 流程和数值问题在 `v0.3.0` 中作了修复。历史测量仍可在上述条件下参考；新部署请使用后续版本并阅读其验证说明。
