## 1. 整改结论

独立审计列出的 14 个确认问题已经逐项修改，并为会改变正式产物的分支补充了失败回归、
真实 FSL 小型 A/B 或可执行的同输入数值门禁。旧 v0.3.0 Release 将由本整改候选直接替换，
版本号保持 `0.3.0`。

整改后的准确结论是：

- 已确认的流程、接线、坐标组合、阈值、cache、CLI 和 QA 缺陷均已关闭；
- legacy 与真实 FSL 的逐阶段/最终输出通过 16 项冻结容差门禁，但不是逐位一致；
- TOPUP、EDDY、FNIRT 和 conductivity/FEM 的完整真实被试闭环仍属于证据边界，不能由
  100% coverage 或局部算子测试外推为所有分支数值等价；
- GRE 科学主线继续采用修正官方 shell 参数计数错误后的 `intended-gre` 行为，不冒充
  安装版脚本的字面 off-by-one 行为。

## 3. legacy 同输入 FSL 数值门禁

公开 `synthetic-legacy-v1`、8 workers、相同 shape/precision 下，整改候选相对 FSL
`6.0.4:ddd0a010` 的关键结果为：

| Artifact | 指标 |
| --- | ---: |
| exact-b0 aligned nodif | relative L2 `9.48847e-5` |
| pass 1 corrected 4-D | relative L2 `5.97549e-4` |
| pass 2 corrected 4-D | relative L2 `1.02061e-3` |
| mean-DWI-to-nodif matrix | max abs `0.0269431 mm` |
| direct-b0 matrices | max abs `0.00327017 mm` |
| final per-volume matrices | max abs `0.0442867 mm` |
| final corrected DWI | relative L2 `0.00544438` |
| final corrected diffusion mean | relative L2 `0.00773141` |
| BET mask | Dice `0.9931947` |
| common-mask FA | relative L2 `0.0300902` |
| compat46 bvec | byte exact |

旧发布的 corrected-DWI/mean relative L2 分别为 `0.00910157/0.01301920`。本次恢复完整
FLIRT schedule 后降为 `0.00544438/0.00773141`。无噪声尖锐 fixture 的近零 tensor 与
SSE 相对误差分别为 `0.772600/1.067618`，会被很小的边界配准差放大；它们被保留为防
回归阈值，但不作为全网格 tensor 等价声明。

门禁实现在 `tools/compare_legacy_stages.py`，阈值冻结于
`tests/fixtures/reference/synthetic_legacy_reference.json`。命令会实际重算候选逐阶段结果、
读取 FSL reference、比较最终产物，并在任一阈值失败时返回非零状态。本次 16/16 通过。

FLIRT remaining matrix 差异来自 float32 cost 的近似并列候选导致 search scale 轨迹分叉；
项目与 FSL 在同一矩阵上的 mutual-information/correlation-ratio cost 一致，但 optimizer
endpoint 不是逐位相同。因此这里只认定“同算法 schedule 且通过冻结数值容差”，不认定
bitwise optimizer equivalence。

## 4. 其他关键数值与合同验证

- GRE composition：`9x9x3` ramp、常量 y 向 1 voxel shift、绕中心 90 度 premat；整改
  结果与真实 FSL `applywarp --abs --premat` 全数组 exact，旧实现中心值相差 99。
- FSL direct probes：显式配置 `dtifit`、BET、`fslmaths`、`convertwarp`、`vecreg` 后，
  定向批次全部通过。
- full tests：`579 passed, 5 skipped`；5 个 skip 均为未配置的可选 FSL executable，
  显式配置后相关批次无 skip。
- coverage：`12,935/12,935` production statements，`100.00%`；包含真实 synthetic
  TOPUP、EDDY、FNIRT/PPD E2E，没有使用 omit/pragma 或降低阈值。
- lint/static：Ruff、`compileall`、JSON 与 `git diff --check` 通过。

## 5. 主动差异与未外推边界

以下内容不是静默缺陷，必须继续作为公开边界：

1. EDDY 默认 seed 为 1，以获得跨平台可复现结果；官方默认 time seed 不可复现。seed 会
   写入 QA，调用者可以显式设置。
2. external susceptibility field + no-TOPUP EDDY 是项目扩展；manifest 明确标记来源，
   不称为官方 TOPUP basename 路径。
3. wrapped phase/PRELUDE、任意 FSL command 配置、multishell 单 tensor 静默拟合、官方
   interactive mesh QA 不在固定运行子集。
4. 本整改没有生成修复 commit 绑定的完整 HCP legacy+nonlinear、nonzero reverse-PE
   TOPUP→EDDY 或真实全链 conductivity/FEM 新结果。历史被试证据可以保留为背景，不能
   代替当前快照的完整官方同输入闭环。

因此替换后的 v0.3.0 可以声称“关闭独立审计确认的 14 项缺陷，并通过当前冻结的局部与
synthetic 数值门禁”，不能声称“所有 FSL optimizer、所有输入与真实被试端到端逐值相同”。
