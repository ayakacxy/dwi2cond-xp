## 1. FNIRT：导数与内部存储方向

### 原因

旧实现把三线性插值得到的 voxel 导数简单除以正 voxel size。这只在轴对齐且不需要 FSL neurological→radiological 内部规范时成立。对 positive-determinant moving affine，x 方向符号会错；只修符号仍不足以复现 FSL 在金字塔和 spline 优化前的内部存储方向。

### 修复

1. 每个导数组件都以固定 float32 累加顺序计算 `gradient_voxel @ moving_mm_to_voxel[:3,:3]`。
2. reference 或 moving 为 positive determinant 时，沿 voxel-x 翻转数据和对应 mask，并组合 voxel flip affine，使内部网格 determinant 为负。
3. spline coefficient 保留 FSL 内部 radiological 顺序；reference 为 neurological 时，只把展开后的 nonlinear field、Jacobian 和 bias field映射回公开 reference 网格。

### 同输入证据

在 `24×23×22` positive-determinant synthetic endpoint 上：

- 修复前 local→FSL corrected-image relative L2：`0.0497437`；
- 修复后 local→FSL corrected-image relative L2：`0.00128790`；
- 修复后 local→reference：`0.0162972`，FSL→reference：`0.0158764`；
- displacement field local→FSL relative L2：`0.175489`，max abs：`0.994549 mm`。

该小型 endpoint 对完整优化器场仍较敏感，所以 field 阈值用于防止方向/量级回归，不用于宣称 whole-optimizer bitwise 等价。图像端误差降低约 38.6 倍，且三轴全支持有限差分均通过 `rtol=2e-3, atol=2e-3`。

## 2. raw-b0 MCFLIRT：raw moving、`fix2D` 与末次插值

旧实现对 reference 和 moving 都建立各级 isotropic pyramid，导致 moving 在优化采样前已经发生一次插值。官方 MCFLIRT 的正确合同是 reference 可按级构造，而 moving 由 raw 数据在 cost sampling 中直接读取。

整改后：

- reference volume 仍按 `8/4/2/1 mm` 调度；
- moving volume 保持 raw grid，并显式传入原始 spacing；
- 薄层首级恢复 `Rz, Tx, Ty` 三参数 `fix2D`、`0.1 mm` smoothing、8 mm z spacing 和官方 padding 顺序；
- 最终 aligned volume 使用 trilinear + FSL extraslice 边界，而不是 SciPy nearest 外推。

真实 MCFLIRT/fslmaths 回归锁定 mean relative L2 `<1.5e-3`、matrix relative L2 `<3e-2`，并单独断言 moving 未进入 pyramid resample。

## 3. sinc：按调用者区分窗口和 padding

官方三个调用者并非同一个 sinc：

| 调用者 | 窗函数 | width | 坐标 padding |
|---|---|---:|---:|
| FLIRT final resample | Hanning | 7 | 1 voxel |
| MCFLIRT pass-2 mean | Blackman | 7 | 1 voxel |
| APPLYWARP composed final | Blackman | 7 | 0 voxel |

本地现在分别使用 `sinc-flirt`、`sinc-mcflirt`、`sinc-applywarp`。通用 `sinc` 仅为向后兼容 API，正式流程不再依赖其模糊语义。真实 FSL 采样回归要求 relative L2 `<2e-6`、max abs `<1e-3`；向量化参考核和 Numba 优化核在测试坐标上 bitwise 相同。

## 4. TOPUP、vecreg 与 post-mask

- TOPUP 保留 final joint support 内的共同 arithmetic-mean scale，并在 support 外 exact zero；真实 FSL 比较固定使用 SimNIBS 4.6.0 的 `b02b0_nosubsamp.cnf`，不以标准 `b02b0.cnf` 代替。
- affine vecreg source-mask 只在 `source_mask_mode="fsl-vecreg"` 下使用显式 half-away-from-zero，避免改变其他 API 的既有 SciPy 行为。
- nonlinear post-mask 只把最终 output mask 改为正值判断，未扩大到 source/reference masks。

## 5. FEM 失败事务

每次 solve 现在写入同级隐藏 attempt 目录。只有 manifest 动态 inventory 在 attempt 路径验证成功后，才把内部路径重写到正式目录并原子发布。若任何阶段失败：

1. 当前 attempt 或刚发布的新目录被保留为 `.failed-<attempt-id>`；
2. failure manifest 记录 `failed_phase`、错误类型、错误文本和失败目录；
3. 若此前已有 completed 输出，则恢复该 last-known-good 目录；
4. runner stage manifest 记录 producer failure manifest 路径和完整 payload。

测试同时覆盖“新 solve 失败”和“新输出已发布但最终验证失败”两种回滚时点，旧 manifest 与 mesh 均按字节保持不变。
