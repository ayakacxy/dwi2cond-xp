## 1. 执行摘要

### 1.1 对用户三个核心问题的直接回答

| 审计问题 | 复审判定 |
| --- | --- |
| 算法流程是否与官方相同 | **主干相近，但 EDDY 不是同一控制流。** legacy、nomoco、最终 WLS、FLIRT/FNIRT→vecreg→T1 mask 的阶段顺序基本对应；EDDY 缺失 interspersed-b0 运动初始化，且最终 `--repol` 检查位于错误位置。 |
| 具体算法实现是否一致 | **部分一致。** 有限正常输入 WLS、给定正确 FSL matrix 的 affine vecreg、PPD 核心公式和 `dir/vn/mc` 有强正证据；EDDY shell/final repol、TOPUP iout、public world-transform basis 和 strict-FSL 部分 NaN 均确认不一致。 |
| 计算逻辑是否一致 | **不能认定一致。** 部分 NaN 的真实 FSL A/B 已产生 tensor relative L2 `0.27845`、S0 relative L2 `234.66`；当前公开 EDDY endpoint 的 corrected-DWI relative L2 为 `0.00819`，且 parameters/replacement 控制流已有源码反例。 |
| 是否可以继续宣称“v0.3.0 与官方实现相同” | **不可以。** 可表述为“固定子集的多数阶段已复现，若干局部算子通过 A/B”；官方兼容性 P0/P1 关闭并补齐同输入阶段级门禁前，不应表述为完整同流程或完整数值等价；可靠端到端产品声明还需另行关闭 cache/FEM 状态合同。 |

### 1.2 最优先阻断等价结论的五个问题

1. **D2C-030-016（P0）：EDDY 缺失 interspersed-b0 到 DWI 的运动初值插值。**
   官方在 b0 registration 后、DWI registration 前按 acquisition volume 位置插值 b0
   movement；当前实现把所有 DWI movement 初始化为零。
2. **D2C-030-017（P0）：EDDY 最终 `--repol` 的位置和 GP fudge factor 均不同。**
   官方在 PEAS shell alignment 后以 fudge factor `1` 做 final outlier check；当前实现在
   PEAS 前以默认 `10` 检测并替换。
3. **D2C-030-015（P1）：strict-FSL 部分 NaN 的 mean/S0 clamp 语义不同。**
   当前实现使用有限值均值，FSL `Sum()/Nrows()` 传播 NaN；真实 `dtifit` A/B 已证明会
   改变 tensor、S0 和 SSE。
4. **D2C-030-018（P1）：single-shell 判断既不等于 FSL grouping，项目内部也不一致。**
   同一组 b-values 可在上游 validator、EDDY 和 FSL 得到三个不同结论。
5. **D2C-030-029（P1）：公开 world-transform API 可在不同 NIfTI basis 下旋转错 tensor。**
   有效 oblique fixture 的真实 vecreg A/B relative L2 为 `0.37796`；自动 T1 主路径安全，
   但公开 CLI/API 及后续方向性 conductivity 受影响。

## 3. 官方流程与当前实现的阶段映射

### 3.1 SimNIBS 4.6 固定流程

```text
prefit tensor
└─ copy/reorient → tensor_decomp → T1 registration

raw single-shell DWI
├─ canonical reorientation；复制 bvals/bvecs
├─ exact b==0 → MCFLIRT 6 DOF → mean b0 → BET -f 0.2
├─ correction 前 raw DTIFIT WLS（FA/SSE QA）
├─ correction branch
│  ├─ nomoco
│  ├─ EDDY without TOPUP
│  ├─ TOPUP → EDDY
│  └─ legacy two-pass registration，optional GRE/FUGUE
├─ corrected DWI `-thr 0`
└─ DTIFIT --wls --sse --save_tensor

T1/head model
├─ labeling 1..499 → T1 brain mask
├─ primary FLIRT 6/12 DOF
├─ linear vecreg 或 FNIRT subsamp=8,4,2,2 → nonlinear vecreg/PPD
├─ 无条件 T1 brain post-mask
├─ tensor_decomp
├─ corrected/raw 6 DOF FA/SSE QA
└─ m2m_<subject>/DTI_coregT1_tensor.nii.gz

SimNIBS conductivity/FEM consumer
└─ tensor sampling → FSL basis correction → dir/vn/mc → SimNIBS FEM
```

关键官方位置：

- raw canonical、exact-b0、BET、raw WLS：`dwi2cond.prepro.source.sh:33-100`；
- no-TOPUP/TOPUP EDDY：`dwi2cond.prepro.source.sh:117-143`；
- legacy/GRE、`-thr 0`、DTIFIT：`dwi2cond.prepro.source.sh:146-177`；
- T1/FNIRT/vecreg/post-mask/QA：`dwi2cond.t1reg.source.sh:19-65`；
- diffusion-only mean 的 exact `b>0`：`dwi2cond.functions.source.sh:327-351`。

## 4. 确认问题：核心算法与控制流

严重度定义：

- **P0**：标准有效输入上可静默改变正式 DWI/tensor 或其关键变换，直接阻断等价结论；
- **P1**：特定有效分支、正式数值/科学 QA 输出、输入/API 合同或缓存完整性可改变结果
  或正式科学判读；
- **P2**：复现身份、异常或尚未支持的输入边界、低风险辅助 artifact，或尚未形成正式
  结果反例的完整性风险；
- **P3**：不改变科学数组，仅错误记录元数据或诊断值。

### D2C-030-015（P1，E3）：strict-FSL 部分 NaN 的 mean/S0 clamp 语义错误

**当前实现**：[`tensor_fit.py:164-175`](../src/dwi2cond_xp/tensor_fit.py#L164) 对信号
使用有限值求和除以 finite count；该均值参与初始和最终 S0 clamp。

**官方实现**：`/usr/local/fsl/src/fdt/dtifit.cc:331-349` 使用
`S.Sum()/S.Nrows()`。本机 armawrap 的
`functions_base.hpp:66-70` 将 `Sum` 实现为 `arma::accu`；只要一项为 NaN，均值即为
NaN，后续 `< mean` 比较为 false。当前 strict NIfTI 路径允许部分 NaN 进入拟合，见
[`nifti_fit.py:131-142`](../src/dwi2cond_xp/nifti_fit.py#L131) 和
[`nifti_fit.py:416-426`](../src/dwi2cond_xp/nifti_fit.py#L416)，因此不是不可达分支。

**真实 FSL A/B fixture**：每个 voxel 的 11 个 volume 为：

```text
[1, 2, 100, 200, 300, NaN, 500, 600, 700, 800, 900]
```

其中前两个为 b0，后九个为 b=1000。结果：

| 输出 | current v0.3.0 | FSL 6.0.4 | 差异 |
| --- | ---: | ---: | ---: |
| tensor | — | — | relative L2 `0.2784486688`；max abs `0.0016427911` |
| S0 | `410.2999878` | `1.74110115` | relative L2 `234.6554579` |
| SSE | `22.3955612` | `113.5842285` | relative L2 `0.80282860` |

复现目录：`/tmp/d2c-nanmean-audit.jBzIJD/`。现有 NaN 单元/FSL 测试使用平滑物理信号，
错误 clamp 分支没有触发，所以通过不能反驳该反例。

**影响**：只影响包含部分 NaN 且触发 clamp 的 voxel；正常有限输入不受影响。但
`strict-fsl` 名称承诺的是 FSL 语义，不能用更“鲁棒”的 finite mean 静默替代。

**验收要求**：复现 FSL 的 NaN 传播和 `MaximumAbsoluteValue` 行为；增加部分 NaN、
all-NaN、Inf、全非正信号以及 workers=1/2 的真实 tensor/S0/SSE A/B。更鲁棒行为只能
保留在显式 `robust` 模式。

### D2C-030-016（P0，E2）：EDDY 缺失 interspersed-b0 运动初始化

**当前控制流**：[`eddy.py:3045-3088`](../src/dwi2cond_xp/preprocessing/eddy.py#L3045)
先拟合 b0，随后调用 DWI 迭代，但没有把 b0 movement 插值结果传给 DWI；
[`eddy.py:2623-2633`](../src/dwi2cond_xp/preprocessing/eddy.py#L2623) 因此把所有 DWI
movement 初始化为零。

**FSL 控制流**：

- `/usr/local/fsl/src/eddy/ECScanClasses.cpp:902-908`：当 b0 数量大于 2、首个 b0 位于
  前 25%、末个 b0 位于后 25% 时认定为 interspersed；
- 同文件 `:924-932`、`:1516-1539`：按 acquisition volume 位置 bracket 并线性插值
  b0 movement，写入每个 DWI 的初值；
- `/usr/local/fsl/src/eddy/eddy.cpp:534-536`：该步骤位于 b0 registration 后、DWI
  registration 前。

**为什么现有门禁未检出**：公开 synthetic EDDY fixture 在
`tools/generate_synthetic_eddy_fixture.py:177-178` 只有两个开头 b0，官方分支永远不会
触发。

**影响**：对有效的 interspersed-b0 采集，非线性 DWI 优化从不同初值出发，可改变
movement/EC 轨迹、corrected DWI、`.eddy_parameters` 和 rotated bvecs。这里不要求证明
每个数据集最终都不同；初始状态和官方控制流已确定不同。

**验收要求**：构造至少 12 个 volume，在 `0、N/2、N-1` 放置有已知渐进刚体运动的
b0；比较 DWI 第 0 次更新前 movement、完整 history、最终 parameters、rotated bvecs 和
corrected DWI。FSL 应显式固定 `--initrand=1`。

### D2C-030-017（P0，E2）：EDDY final `--repol` 的顺序及 GP fudge factor 不一致

**当前顺序**：

1. [`eddy.py:2931`](../src/dwi2cond_xp/preprocessing/eddy.py#L2931) 应用 DWI location
   reference；
2. [`eddy.py:2934-2945`](../src/dwi2cond_xp/preprocessing/eddy.py#L2934) 立即执行 final
   outlier detect/replace；
3. 返回外层后，[`eddy.py:3092-3122`](../src/dwi2cond_xp/preprocessing/eddy.py#L3092)
   才估计和应用 PEAS shell alignment。

final check 的 `load_prediction_state()` 使用
[`estimate_spherical_gp_hyperparameters`](../src/dwi2cond_xp/preprocessing/eddy.py#L319)
默认 `error_variance_fudge_factor=10.0`。

**FSL 顺序**：

1. `/usr/local/fsl/src/eddy/eddy.cpp:102-132` 先 location reference，再做 PEAS；
2. 同文件 `:320-327` 在 PEAS 后才运行 `FinalOLCheck`；
3. final check 前把默认 fudge factor 从 `10` 临时改为 `1`，完成后恢复；
4. `eddy.cpp:796-819` 用这组重新估计的 GP prediction 执行最终 detect/replace。

**影响**：当前 outlier map 在错误的 movement 状态上计算，且预测误差方差是官方 final
check 的十倍；反过来，当前 PEAS 又会看到已被提前替换的数据。可能同时改变：

- PEAS translation/rigid 参数；
- final outlier map 和 replacement values；
- outlier-free scan-space data；
- `.eddy_parameters`、rotated bvecs 和最终 corrected DWI。

**现有测试为什么不足**：complete-runner 测试 monkeypatch 了 DWI registration 并设置
`replace_outliers=False`；冻结 fixture 的 seeded hyperparameter 比较验证的是普通 factor
10，不是 final factor 1；四个强人工坏片离阈值过远，即使顺序错误也可能同样被检出。

**验收要求**：锁定调用序列

```text
DWI iterations → location reference → PEAS → final GP(ff=1)
→ detect → replace → final resample
```

并增加接近 4σ 阈值、带非零 shell 刚体错位的 fixture；同输入比较 PEAS、final outlier
map、outlier-free data、parameters、rotated bvecs 和 corrected DWI。

### D2C-030-018（P1，E2）：single-shell 判定不是 FSL shell-group 语义，且项目内部不一致

当前 [`eddy.py:2977-2984`](../src/dwi2cond_xp/preprocessing/eddy.py#L2977) 要求任意两个
diffusion b-value 的差均 `<100`；更上游的
[`gradients.py:57-77`](../src/dwi2cond_xp/gradients.py#L57) 又使用
`max(shell)-min(shell) <= 100`。因此差值恰好 `100` 时，上游 validator 接受、EDDY 拒绝。

FSL `/usr/local/fsl/src/eddy/EddyUtils.cpp:50-80` 则先按模板值把每个 b-value 分配到
`<100` 的 group，再计算 group mean，并以 mean 做最终 assignment；它不是任意两值比较，
也不是简单的全局 range。

最小反例：

```text
b-values: [1000, 901, 1099]
current pairwise rule: false
FSL grouping: one shell, group mean 1000, true
```

这里三值用于隔离 shell predicate；形成满足 EDDY 方向数要求的完整输入时，可把三值重复
两次并加入 b0，判定差异不变。

当前实现会拒绝 FSL 接受的固定单壳输入；在 exact-100 边界还会在两个本地入口得到不同
结论。现有测试只覆盖两值恰好相差 `99.999/100`，没有覆盖 group-template 传递性或
两个本地 validator 的一致性。

**验收要求**：移植 FSL group/mean/assignment 语义，并加入上述三值反例、输入顺序置换、
边界 `<100`/`==100`/`>100` 测试。

## 6. 确认问题：流水线、复现与 QA

### D2C-030-022（P1，E2）：stage 失败后可遗留旧 output 并在下一次被当成新结果

[`PipelineRunner.run_stage`](../src/dwi2cond_xp/preprocessing/pipeline.py#L297) 先直接执行
action，再验证正式 output；失败时只原子写 failed manifest，不隔离或清除 action 已写出的
正式路径。

最小状态机反例：

1. 第一次 action 写出 outputs A、B，然后抛异常；B 留在正式目录；
2. 第二次 action 只写出 A 并正常返回；
3. `validate_artifacts` 看到新 A + 旧 B，stage 被记录为 completed。

实际探针得到 `A=A2`、`B=B-stale`、最终 `status=completed`，不是只根据代码推测；
复现目录同为 `/tmp/dwi2cond-pipeline-audit.zRwGh2/`。

**影响**：任何非原子多文件 stage 都可能发布跨 attempt 混合产物。输出哈希本身无法证明
同一次 action 生成了全部文件。

**验收要求**：优先在 attempt-specific 临时目录执行并整体原子发布；至少也要在运行前
精确清理本 stage 声明的旧 outputs。增加“首轮部分写后失败、次轮漏写一个文件”的两次
运行测试。

### D2C-030-023（P2，E2）：聚合 QA 默认 b0 阈值与官方 exact-zero 合同不同

**验收要求**：官方兼容流水线显式传 `0.0`；如需常规 MRI 的阈值策略，应作为独立 QA

### D2C-030-024（P2，E1）：cache identity 未包含数值运行时和底层线性代数实现

[`pipeline.py:245-266`](../src/dwi2cond_xp/preprocessing/pipeline.py#L245) 的 identity 由输入、

可执行反例中，一个 tensor voxel 含 NaN 时 `validate_simulation_inputs(mode="vn")` 通过，
`tensors_to_conductivity` 随后产生全 NaN；另一个 scalar dry-run 接受 shape/affine 都不同的
T1 与 final_tissues。真实后端可能稍后失败，但不能把昂贵 solve 后的偶然失败当作输入验证。

**验收要求**：建立共同 NIfTI contract validator；各向异性模式在 SESSION 创建前检查
tensor finite，所有模式检查 T1/final_tissues grid；记录 checked voxel 数和 grid identity。

### D2C-030-036（P2，E2）：register-tensor source mask 只查 shape，不查 affine

[`registration.py:105-147`](../src/dwi2cond_xp/registration.py#L105) 对 source mask 只检查
shape；同函数对 reference mask 却检查 shape+affine。相同 shape、affine 平移一 voxel 的
source mask 会被按 tensor 数组下标直接使用，实测可静默错选 valid support。

FSL vecreg 同样假定调用者提供正确 grid，因此这是项目公开 API/文档安全合同缺口，不是
FSL 数学公式差异。验收应在采样前要求 source mask 与 tensor grid exact，并覆盖
same-shape/different-affine 反例。

### D2C-030-037（P2，E2）：`run_tdcs` 的构建/后处理异常会把 manifest 永久留在 running

[`simulation.py:275-304`](../src/dwi2cond_xp/simulation.py#L275) 只把 `run_simnibs` 放进
try/except；`build_tdcs_session` 与完成后的 subject-volume masking 在 try 外。非法 solver
的最小复现中函数抛 `ValueError`，但已经写出的 manifest 仍为 `"running"`；后处理 grid
失败也有同样状态污染。

**验收要求**：从 SESSION build 到所有 postprocess/manifest finalize 统一纳入事务；任意
异常都原子写 `failed`、error type/message，并区分 solve 已完成但后处理失败的状态。

### D2C-030-038（P1，E2）：TOPUP `iout` 恢复了错误的逐 volume 强度比例

[`topup.py:2473-2479`](../src/dwi2cond_xp/preprocessing/topup.py#L2473) 把两个输入分别缩放
到均值 100；[`topup.py:2593-2595`](../src/dwi2cond_xp/preprocessing/topup.py#L2593)
输出时又分别乘回各自的 `input_means[index]/100`。

FSL `topup.cpp:132-142` 虽也分别标准化输入，却另外计算所有输入原始均值的 `gmean`；
`topup.cpp:227-236` 和 `topup_costfunctions.cpp:1104-1127` 对全部 corrected volumes 使用
同一个 `gmean/100`。SimNIBS 固定配置启用 `--scale=1`，所以该分支真实可达。

最小反例把 reverse-PE b0 的整体强度设为 forward 的两倍：场估计前两者都会归一至 100；
FSL `iout` 两卷恢复相同公共尺度，本地却恢复约 `1:2`。这改变 corrected pair 的数值合同。
SimNIBS 通常只取第一卷做 BET，纯全局尺度下 mask 大体不变，但固定绝对阈值或直接消费
corrected pair 会受影响。

**验收要求**：全部 corrected volumes 统一使用 `mean(input_means)/100`；增加不等均值双 b0
的真实 FSL A/B，同时保留等均值回归。

### D2C-030-039（P1，E2）：legacy MCFLIRT 缺少官方薄层 `fix2D` 分支

当前 [`legacy.py:76-150`](../src/dwi2cond_xp/preprocessing/legacy.py#L76) 始终运行普通三维
多阶段注册，[`rigid.py:668-704`](../src/dwi2cond_xp/preprocessing/rigid.py#L668) 也始终开放
三维参数。FSL `mcflirt.cc:367-397` 在 `zsize<3`、z-FOV `<20 mm` 或显式 2D 时复制端层、
设置 `twodcorrect=1/smoothsize=0.1`；`mcflirt.cc:220-243` 只优化 `Rz/Tx/Ty`。

对 `16×16×2` 或 z-FOV 小于 20 mm 的有效薄层输入，本地会开放 FSL 明确禁止的 out-of-plane
自由度，矩阵与重采样可能不同。正常全脑三维 DWI 不受影响。

**验收要求**：实现同一 `fix2D` 判断、端层复制和三参数优化；若固定子集决定不支持，应在
入口显式拒绝，不能静默运行另一算法。

### D2C-030-040（P2，E2）：EDDY 退化 outlier 统计的失败语义不同

[`eddy.py:3626-3630,3653-3656`](../src/dwi2cond_xp/preprocessing/eddy.py#L3626) 在少于两个
eligible slices 或零方差时主动抛错；FSL `EddyHelperClasses.cpp:578-629` 继续做除法，后续
NaN comparison 通常为 false，因此不标记 outlier 并继续。

这不是正常全脑主路径问题，但 strict compatibility 对小 z、全相同 residual 或退化 mask
会一边失败、一边完成。应选择复现 FSL，或在公开合同中把这些输入显式排除并在计算前给出
稳定错误；测试需冻结两种退化条件。

### D2C-030-041（P2，E2）：FNIRT 缺少官方 self-registration identity 快路径

FSL `fnirt.cpp:130-140`、`fnirtfns.cpp:1133-1175` 在 input 与 reference 是同一图像且 affine
为 identity 时直接写 identity deformation/Jacobian；当前
[`fnirt.py:2333-2547`](../src/dwi2cond_xp/preprocessing/fnirt.py#L2333) 仍进入完整四级优化。

正常 FA→T1 主路径不会触发，但 public API 对同一有效输入的控制流、耗时和官方 bitwise
identity 保证不同。本轮尚未以 E3 证明本地优化后的正式数组偏离 identity，因此本项保留
P2，不能表述成已经确认的科学数组错误。应实现快路径，或明确排除 self-registration；
增加 coefficient、field、Jacobian 和 warped image identity 测试。

## 9. 主动差异与需要冻结的兼容决策

下列项目确实与官方字面行为不同，但当前证据不足以直接称为科学 bug；修改前应先明确
项目要复现安装版字面行为，还是保留主动修正/统一 schema。

### 9.1 GRE dwell time 精度

当前使用 `milliseconds / 1000.0`；官方 shell 用 `bc scale=5` 截到小数点后五位。例如：

```text
input     0.789 ms
current   0.000789 s
official  0.00078 s
```

字面位移比例相差约 `1.15%`。若保留更精确值，应在文档中声明为主动修正并提供明确的
literal compatibility 策略；不能同时称“逐字复现 FSL shell”。

### 9.2 已知默认策略与范围差异

- 当前默认固定 `random_seed=1`；官方 SimNIBS 不传 `--initrand`，FSL 默认按当前时间设种。
  严格 A/B 必须给 FSL 显式传 `--initrand=1`；
- 当前 EDDY 主动限制单壳；FSL EDDY 本身可处理更广范围；
- GRE 只接受 rad/s fieldmap，不覆盖 Siemens phase+TE→PRELUDE；
- TOPUP 固定子集只接受 x/x-/y/y-；
- 官方 SimNIBS 的负 PE 语法是 `-x/-y/-z`，项目公开语法是 `x-/y-/z-`；
- full raw-GRE workflow 没有官方 `--dontdenoise` 等价开关，固定走 median filter；
- 项目不生成 `first_ev_for_check.msh`，也不复刻 FSLeyes/Gmsh 交互检查和 HTML log；
- FEM 未启用时项目不要求 `final_tissues.nii.gz` sentinel，官方 T1 path 会检查；
- 项目保留 intermediates 和 artifact cache，官方 shell 默认清理若干中间目录；
- legacy `compat46` 不旋转 bvec，与旧 SimNIBS `EDDY_CORRECT` 脚本一致；
- GRE 应用 warp 的实现是对上游 `$# -gt 5` off-by-one 的 intended correction，不是安装版
  shell 的 literal behavior；
- external susceptibility field + no-TOPUP EDDY 是项目扩展；官方不允许 GRE fieldmap 与
  EDDY 组合；
- FEM 是本项目在官方 `dwi2cond` shell 之后增加的 consumer，不应混作 shell 等价性。

## 10. 已排除的误判

### 10.1 无 field 时未运行 offset/movement separation

这不是问题。当前仅在 prepared field 存在时运行 separation；FSL 无 field 时虽进入同名
调用，但 `HasFieldOffset()==false`，立即 no-op。两侧计算等价，不应为了“命令顺序相同”
增加无效逻辑。

### 10.2 TOPUP movement 未直接传入 EDDY

官方把 TOPUP basename（coefficient + movement）交给 EDDY，当前主要传 dense field。
但 SimNIBS 固定 DWI index 全为 1，TOPUP 第一 scan 又是零运动参考，因此目前不能仅凭
接口形状判定主路径有 movement bug。仍需 coefficient reader 与 dense field 的同输入
插值 A/B；在有反例前应列为证据空白，不应写成确认缺陷。

### 10.3 无 field 时 `.eddy_parameters` 被误读为 15 列

这也是误判。`QuadraticScanECModel(field=false)` 仍分配 10 个 EC 参数；`_nepd=9` 只控制
导数数量，`NParam()` 仍返回 10。`WriteParameterFile(ANY)` 按 `NParam()` 写出
`6+10=16` 列，最后一列为零。源码位置为
`/usr/local/fsl/src/eddy/ECModels.h:300,359,475-488` 和
`ECScanClasses.cpp:1157-1168`。

当前公开 fixture 实测 FSL 与本地 parameter table 都是 `(26,16)`。因此 15/16 列差异
不得进入问题清单，也不需要为这一误判修改实现。

### 10.4 特征向量逐体素正负号不同

随机 504 个 SPD tensor 中，V1/V2/V3 分别有 `220/231/210` 个体素与 FSL 点积小于零；
逐体素按轴符号对齐后最大绝对误差为零，L1/L2/L3 也 exact。DTI 特征方向是无向轴，
`v` 与 `-v` 表示同一张量方向，PPD 与 conductivity 对该符号不敏感。这是允许的本征向量
符号自由度，不是计算错误；验收应使用 axial angle，不应强迫逐元素同号。

### 10.5 其他已核销候选

- GRE 4-D magnitude：官方取第 0 volume，本地也取第 0 volume，不是差异；
- legacy GRE affine+warp：本地行为是对官方 shell 参数计数 off-by-one 的 intended fix，
  不是新的组合公式错误；
- TOPUP LM/SCG/PCG、EDDY 普通 unit-damped GN accept/reject、FNIRT 四级 schedule：二轮
  逐源码和 debug 未找到新的公式/控制流分歧；终点不 exact 已按证据边界报告，不能反向
  虚构 bug；
- conductivity 中看似反常的 FSL basis correction 与 normalization 次序：本地和 SimNIBS
  `cond_utils.py` 相同，不应擅自“纠正”。

退出条件不是“新增单元测试通过”，而是同一输入、相同 seed/线程/精度下，比较中间状态、
参数 history、outlier map、rotated bvec、corrected DWI、tensor/S0/SSE，并说明每个容差来源。

### 第二批：恢复正式数据谱系和可复现产物

1. 拆分 raw/corrected DWI 与 mask，所有 QA 消费 producer artifact 并检查 affine/grid；
2. official FNIRT wrapper 强制 T1 post-mask；
3. FEM manifest/cache 纳入所有动态 output 的内容哈希；

6. source mask 核对 affine；`run_tdcs` 将 build/solve/postprocess 全部纳入 failed-state 事务。

每个问题关闭时应单独记录：修复 commit、失败前反例、修复后同输入结果、误差、测试命令、
未验证边界。不要再次只用总测试数或 coverage 百分比关闭算法问题。

## 13. 最终审计结论

当前 v0.3.0 不是从零开始的错误实现：默认 legacy/T1 主干、有限正常输入 WLS、张量分量、
给定正确 FSL matrix 的 affine vecreg、nonlinear PPD 和 conductivity 已有扎实的源码与
数值正证据，旧审计的 14 项整改也确实改善了实现。

但“多数阶段存在且测试通过”不等于“与官方相同逻辑”。本轮在当前 tag 上确认：

- 默认 EDDY 有两个核心控制流差异，公开 no-repol 又有一个独立语义错误；
- single-shell 输入判定、TOPUP `iout` 强度恢复和薄层 MCFLIRT 分支不同；
- strict-FSL 对部分 NaN 有真实数值反例；
- 公开 world-transform 可在不同 NIfTI basis 下旋转错 tensor；
- raw QA、mask/grad-dev、FNIRT public API、FEM/cache 和 stage publication 仍有合同缺陷；
- EDDY/FNIRT 当前 endpoint 仍有未归因数值差异，完整 TOPUP→EDDY、真实 HCP nonlinear
  和真实 FEM endpoint 尚未闭环。

因此应拆开两条关闭边界：

1. 对“官方流程/数值等价”声明，至少先关闭 `015..020,029,031,038,039`，并补齐相应真实
   同输入阶段级 A/B；
2. 对“可靠端到端产品输出”声明，还必须关闭 pipeline/cache/FEM 的 `021,022` 以及会污染
   正式产物的相关数据合同问题。

在上述边界满足前，建议冻结任何“v0.3.0 与官方实现相同”“完整 FSL 等价”或“端到端
数值等价”的对外表述；P2/P3 则必须按公开支持范围逐项关闭或明确排除。准确的当前表述
应是：

> dwi2cond-xp v0.3.0 实现了 SimNIBS 4.6 所需固定 FSL 子集的主要流程，并在若干局部
> 算子和合成阶段取得数值对应；独立复审仍发现 EDDY/TOPUP 控制流与输出、strict-FSL
> 边界语义、公开张量重定向和数据/cache/FEM 合同问题，完整同流程与端到端数值等价
> 尚未证明。
